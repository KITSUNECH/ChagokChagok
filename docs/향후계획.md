# 차곡車곡 – 향후 계획

공모전 안내(공지 「공모전 개발 범위 및 기술 문의 안내」)에 따라, 공개된 Pleos Playground 개발 문서에서 지원하지 않는 기능은 앱에 넣지 않고 여기와 기획서에 향후 계획으로 적습니다.

## 지금 공개 SDK·API로 구현한 것

| 기능 | 쓰는 SDK·API |
|---|---|
| 차량 신호로 주행 기록과 일기 | Vehicle SDK (깜빡이, 브레이크, 와이퍼, 전조등, 안전띠, 좌석, 크루즈, 주행거리, 엔진오일·브레이크액·워셔액) |
| 기어 D에서 시작, P에서 일기 | AAOS CarPropertyManager `GEAR_SELECTION` |
| 목적지, 회전 안내, 제한속도, 편안한 길, 내비 화면 열기 | NaviHelper SDK |
| 한마디를 남긴 자리에서 들려주기 | FusedLocation SDK 근접 알림 |
| 음성 안내 | TextToSpeech SDK (기기 안 합성) |
| 달리는 동안 말로 천천히·한마디 남기기·일기 읽기 | Gleo AI App Integration |
| 차선 변경 기록(기다린 시간, 비·밤)과 그 구간 전 미리 안내 | Vehicle SDK 깜빡이·조향각 + FusedLocation |
| 같은 길에서 늘었는지: 앱의 판단 + 운전자의 느낌, 그래프 | Vehicle SDK(연비·브레이크) + 앱 안 분석 |
| 주행 중 화면 제한 | CarUxRestrictions |
| 같은 차를 쓰는 가족·친구끼리 길 건네기, 응원, 일기 올리기 | 앱 안 운전자 프로필 |

## 플랫폼이 지원하면 더할 것

| 바람 | 지금 공개 문서 기준 | 앱에서 |
|---|---|---|
| 다른 차를 타는 가족·친구와 Pleos 계정으로 잇기 | 써드파티용 계정·프로필 API 없음 | 공모전판에서만 시연용으로 미리 보기 |
| 다른 차의 길 받기 (아빠 차에서 남긴 출근길을 내 차에서) | 차와 차 사이 데이터 전달 API 없음 | 시연용 |
| 같이 가기 (앞서 가는 가족의 위치를 동의 아래 함께 보기) | 없음 | 시연용 |
| 첫 설정에서 Pleos 계정 이름 불러오기 | 써드파티용 프로필 API 없음 | 이름 직접 입력 |
| 차종·트림 자동 인식 | 공개 API 없음 (CarInfo는 차대번호만) | 운전자가 차종을 한 번 고름 |
| 경고등(Telltale)·바퀴별 공기압 | 비공개 권한 | 쓰지 않음 |
| 휴대폰에서 일기 보고 응원 보내기 | 써드파티 연동 API 없음 | 없음 |

## 2차 PT까지

- 잠깐 정차(주유소·등원) 합치기
- SpeechToText SDK로 주차 후 한마디를 말로 남기기
- 같은 차 운전석 바꾸기 잠금
- 에뮬레이터 상황 시험 (내비 전환, 통화·글레오 중 음성, 신호·위치 연결 실패, 주행 중 재실행)
- 대상 사용자 5명 사용성 관찰 (초기 관찰이며 효과의 증거로 쓰지 않음)
