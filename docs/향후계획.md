# 차곡車곡 – 향후 계획

공개된 Pleos Playground 개발 문서에서 지원하지 않는 기능은 앱에 넣지 않고 여기에 향후 계획으로 적습니다.

## 지금 공개 SDK·API로 구현한 것

| 기능 | 쓰는 SDK·API |
|---|---|
| 차량 신호로 주행 기록과 일기 | Vehicle SDK (깜빡이, 브레이크, 와이퍼, 전조등, 안전띠, 좌석, 크루즈, 주행거리, 엔진오일·브레이크액·워셔액) |
| 기어 D에서 시작, P에서 일기 | AAOS CarPropertyManager `GEAR_SELECTION` |
| 목적지, 회전 안내, 제한속도, 편안한 길, 내비 화면 열기 | NaviHelper SDK |
| 한마디를 남긴 자리에서 들려주기 | FusedLocation SDK 근접 알림 |
| 음성 안내 | TextToSpeech SDK (기기 안 합성) |
| 달리는 동안 말로 내 운전 물어보기·여기 어려웠어·한마디 남기기 | Gleo AI App Integration |
| 차가 먼저 말 걸기 (돌기 전 깜빡이, 차선 변경 뒤 한마디, 요즘 신경 쓰이는 것부터) | Vehicle SDK 기록 + TextToSpeech SDK |
| 차선 변경 기록(기다린 시간, 비·밤)과 그 구간 전 미리 안내 | Vehicle SDK 깜빡이·조향각 + FusedLocation |
| 같은 길에서 늘었는지: 앱의 판단 + 운전자의 느낌, 그래프 | Vehicle SDK(연비·브레이크) + 앱 안 분석 |
| 주행 중 화면 제한 | CarUxRestrictions |
| 같은 차를 쓰는 가족·친구끼리 길 건네기, 응원, 일기 올리기 | 앱 안 운전자 프로필 |

## 플랫폼이 지원하면 더할 것

| 바람 | 지금 공개 문서 기준 | 앱에서 |
|---|---|---|
| 다른 차를 타는 가족·친구와 Pleos 계정으로 잇기 | 써드파티용 계정·프로필 API 없음 | 시연판에서만 시연용으로 미리 보기 |
| 다른 차의 길 받기 (아빠 차에서 남긴 출근길을 내 차에서) | 차와 차 사이 데이터 전달 API 없음 | 시연용 |
| 같이 가기 (앞서 가는 가족의 위치를 동의 아래 함께 보기) | 없음 | 시연용 |
| 첫 설정에서 Pleos 계정 이름 불러오기 | 써드파티용 프로필 API 없음 | 이름 직접 입력 |
| 차종·트림 자동 인식 | 공개 API 없음 (CarInfo는 차대번호만) | 운전자가 차종을 한 번 고름 |
| 경고등(Telltale)·바퀴별 공기압 | 비공개 권한 | 쓰지 않음 |
| 휴대폰에서 일기 보고 응원 보내기 | 써드파티 연동 API 없음 | 없음 |

## 사용자 인터뷰에서 나온 요구 (2026-11-14, 3명)

| 요구 | 지금 | 다음 |
|---|---|---|
| 차선 변경 때 앞·뒤·양옆 차의 속도와 거리를 보고 직접 판단하고 싶다 (60대 30년·50대 20년 무사고) | 공개 SDK에 주변 차량 데이터가 없고, 실시간 판단은 제조사가 검증하는 안전 기능. 앱은 끼어드는 순간에는 말하지 않음 | **플랫폼 제안**: 기본 사양에도 있는 후측방 센서 정보를 드라이빙 뷰(또는 슬림 디스플레이)에 "여유 / 주의"로. 그 데이터가 읽기 전용으로 열리면 앱은 어떤 조건에서 차선 변경이 어려웠는지 쌓아 돌려줌 |
| 같은 목적지의 경로 A·B를 요일·시간대·날씨별로 비교하고 싶다 (코스트코, 서부간선 35분) | 같은 길 비교, 시간대·비·밤 조건 표시 | 내 기록·같은 차 가족 기록으로 경로별 소요 시간, NaviHelper 경로 옵션별 예상 시간(`requestTrip`)을 함께 |
| 가속·브레이크 습관과 연비 | 이번 주행 연비, 1km당 브레이크 | 같은 길에서 연비와 브레이크를 나란히 (가속 페달 값은 공개 SDK에 없음) |
| 늘었다는 건 함께 탄 사람의 말로 느낀다 (20대 3년 차) | 운전자의 느낌과 앱의 판단을 합침 | 옆자리에 사람이 탔으면 승차감을 한 번 묻기 |
| 초행길이 가장 어렵다 | 두 번째 방문부터 도움. 초행 길찾기는 내비의 몫 | 같은 차 가족이 먼저 다녀온 길 건네기 |
| 단속 구간·방지턱을 알고 가면 덜 긴장된다 | 없음 | 내비 단속 구간 알림을 위치와 함께 기록해 다음에 미리 알리기 |

## 차가 더 잘 말해 주려면 (가장 먼저 하고 싶은 것)

| 바람 | 지금 | 열리면 |
|---|---|---|
| **"지금 들어가도 좋아요"**: 차선 변경 타이밍을 말로 | 차의 주행 화면에는 주변 차가 보이지만 그 정보는 앱에 열려 있지 않습니다. 못 보는 것을 말하면 위험하므로 앱은 끼어드는 순간에 말하지 않습니다 | 후측방 정보가 읽기 전용으로 열리면, 차선 변경 전 여유를 말로 알려 주고 어떤 조건에서 어려웠는지 일기에 쌓습니다 |
| 급조향·급가속을 재기 | 급정거는 AAOS `PERF_VEHICLE_SPEED`의 속도 변화로 잽니다. 급조향과 급가속은 아직 재지 않습니다 | 속도와 조향각 변화를 합쳐 급조향을, 속도 증가로 급가속을 잽니다 |
| 주차를 더 자세히 | 후진 뒤 기어를 바꾼 횟수를 같은 자리끼리 견줍니다 | 후진을 넣은 때부터 P까지 걸린 시간, 핸들을 되돌린 횟수 |
| 글레오와 긴 대화 | 글레오가 앱을 부르면 기록한 차량 신호로 답합니다. 앱이 글레오의 언어 모델을 직접 쓸 수는 없습니다 | 플랫폼이 대화 맥락을 넘겨주면 이어지는 질문에도 답합니다 |
