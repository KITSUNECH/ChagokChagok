# 차곡차곡 – 기능과 사용법

> **차로 쓰는 성장일기.** 내 운전을 아는 차가 달리는 동안 말을 걸어 주고, 같은 길에서 내가 늘었는지 보여 준다.

이 문서는 기능마다 **어떻게 쓰는지**와 **차량 신호가 화면·음성까지 가는 길(파이프라인)** 을 적은 것입니다.

각 기능 끝의 **검증**은 무엇으로 확인했는지입니다. "테스트"는 자동 테스트(단위·화면)가 그 흐름을 돌린다는 뜻이고, "에뮬레이터"는 Pleos Connect 에뮬레이터에서 직접 봐야 하는 부분입니다.

---|---|
| 코드 | 신호부터 화면·음성까지 코드에서 이어지는 것을 따라가 확인함 |
| 테스트 | 자동 테스트(단위·화면)가 이 흐름을 돌림 |
| 실기 필요 | Pleos Connect 에뮬레이터에서 확인이 더 필요함 |

---

## 1. 한눈에 보는 사용법

| 언제 | 내가 하는 일 | 차(앱)가 하는 일 |
|---|---|---|
| 처음 켰을 때 | 이름, 운전자 종류(지금은 운전 초보), 위치·소리 고르기. 권한 창에서 위치·속도·알림 허락 | 첫 인사 |
| 출발 전 (선택) | 홈에서 "요즘 제일 신경 쓰이는 것" 고르기 | 그것부터 말해 줄 준비 |
| 출발 | 기어를 **D**에 놓는다. 누를 것은 없다 | 기록 시작, "출발해요" |
| 달리는 동안 | 운전만 한다 | 돌기 전에 깜빡이 안내, 차선 변경을 마치면 한마디, 남겨 둔 한마디를 그 자리에서 |
| 멈췄을 때 (선택) | "지금까지 어땠어?" 누르기, 또는 글레오에게 묻기 | 지금까지 기록으로 답함 |
| 도착 | 완전히 멈춘 뒤 기어를 **P**에 놓는다 | 일기 한 장을 만들고 한 줄 말해 줌 |
| 주차 후 | 질문에 답하고(한 번에 하나), 다음에 들을 한마디 남기기 | 차가 본 것과 내 답을 합쳐 보여 줌 |
| 다시 갈 때 | 홈 "다시 갈 길"에서 고르고 D | 지난번 한마디를 그 근처에서 들려줌 |
| 쌓이면 | 일기장에서 길을 고름 | 같은 길에서 늘었는지 판단하고 그래프로 |

## 2. 기능별 파이프라인과 사용법

### 2-1. 기록 시작과 끝

- **사용법**: 기어를 D에 놓으면 시작, P에 놓으면 끝. 홈 맨 위 카드는 지금 차 상태(안전벨트, 연료·배터리, 내비 목적지)를 보여 주는 것이고, 기어 신호를 못 받는 차에서만 눌러서 시작합니다.
- **파이프라인**: AAOS `GEAR_SELECTION`(`Car.kt`) → `MainActivity.onCarEvent` → `Trip.onCar` → `Trip.start()` / `Trip.end()` → `Writer.write` → 저장(`Store.addDiary`) → 일기 화면.
- **규칙**
  - 200m를 가지 않았으면 일기를 만들지 않습니다("잠깐만 움직여서…"). 움직이지 않았으면 "움직이지 않아서…".
  - 거리는 주행거리계 → 지나온 위치 → 속도로 잰 거리 순으로, 있는 것을 씁니다.
  - 속도가 남은 채 P 신호가 오면 끝내지 않고, 멈추면 그때 끝냅니다.
  - 기록 중에는 알림("차곡차곡 기록 중")이 떠 있어 내비를 크게 띄워도 기록이 이어집니다.
- **검증**: 테스트(시작/끝, 이어 쓰기) · 에뮬레이터(200m 규칙, 달리는 중 P)

### 2-2. 속도와 급하게 선 순간

- **사용법**: 권한 창에서 **속도**를 허락해야 합니다. 허락하지 않으면 급정거 없이 기록합니다.
- **파이프라인**: AAOS `PERF_VEHICLE_SPEED`(`Car.startSpeed`) → `Trip.onSpeed` → 시속 20km 넘게 달리다 1초에 약 시속 11km 넘게 줄면 `Evt.HARD` → 일기의 브레이크 줄, 일기장의 하루 요약, 판정의 "급하게 선 횟수".
- **규칙**: 그 순간에는 말하지 않습니다. 속도 신호를 받지 못한 주행에서는 "급하게 선 적 없다"고도 말하지 않습니다.
- **검증**: 에뮬레이터

### 2-3. 돌기 전 깜빡이

- **사용법**: 내비가 회전을 안내하는 중이어야 합니다. 회전이 가까운데 깜빡이가 꺼져 있으면 "지금 오른쪽 깜빡이"라고 말하고 화면에 보여 줍니다. 미리 켰으면 짧게 칭찬합니다.
- **파이프라인**: NaviHelper 회전 안내 + Vehicle SDK 깜빡이 → `Trip.onCar` → `TurnCoach`(`Writer.kt`) → 음성·주행 화면 → `Drive.turns` / `turnsSignaled` → "5번 돌았고 그중 4번은 돌기 전에 깜빡이를 켰어요".
- **검증**: 테스트 · 에뮬레이터(내비 회전 안내가 들어오는지)

### 2-4. 차선 변경

- **사용법**: 깜빡이를 켜고 → 기다렸다가 → 운전대를 조금 돌려 넘어가고 → 깜빡이를 끕니다. 깜빡이를 켜고 3초 넘게 지난 뒤 넘어갔으면 끄는 순간 "깜빡이 켜고 n초, 잘 넘어갔어요"라고 말합니다(한 주행에 세 번까지, 차선 변경을 신경 쓰인다고 골랐으면 다섯 번까지).
- **파이프라인**: Vehicle SDK 깜빡이 + 운전대 각도 → `LaneWatch`(`LaneChange.kt`) → `Evt.LANE` → `Trip.lanePraise` 음성 → 일기의 차선 변경 줄, 판정의 "차선 변경 3초 전 깜빡이".
- **규칙**
  - 운전대를 60° 넘게 돌리면 교차로 회전으로 보고 세지 않습니다. 내비가 300m 안의 회전을 안내 중일 때도 세지 않습니다.
  - 운전대 각도도 내비 안내도 없으면 회전과 구분할 수 없어 세지 않습니다.
  - 3초가 안 돼 넘어간 것은 적지만 칭찬하지 않습니다.
  - 끼어드는 순간에는 말하지 않습니다. 차는 옆 차를 앱에 알려 주지 않습니다.
- **검증**: 테스트(판정) · 에뮬레이터(음성이 실제로 나오는지)

### 2-5. 안전벨트

- **사용법**: 따로 할 일 없음. 벨트를 안 맨 채 출발하면 말과 주행 화면 맨 위로 20초 동안 알려 줍니다.
- **파이프라인**: Vehicle SDK `SeatBeltBuckledState` → `Car.belt` → 홈 카드, 출발 전 확인, 주행 화면.
- **알아 둘 것**: 가상 콘솔에는 안전벨트 조작이 없어 에뮬레이터에서는 늘 "안 맴"으로 나옵니다. 시연판에서는 주행 화면의 **안전벨트 맸어요 (시연)** 을 누르면 넘어갑니다(받은 신호에는 세지 않습니다).
- **검증**: 에뮬레이터

### 2-6. 요즘 제일 신경 쓰이는 것

- **사용법**: 홈에서 차선 변경 · 깜빡이 · 주차 · 브레이크 · 전부 · 모르겠어요 중 하나를 고릅니다. 다시 누르면 풀립니다.
- **파이프라인**: `Coach.focusCard` → 저장 → `Trip.start`에서 읽음 → 출발 말("오늘은 차선 변경부터 봐 드릴게요"), 주차 직후 첫 말, 일기 "오늘 차가 본 것"의 맨 윗줄.
- **규칙**: 기록과 분석은 언제나 전부 합니다. 고른 것은 **무엇부터 말할지**만 정합니다. 달리는 동안 달라지는 것은 차선 변경(칭찬 횟수)과 주차(도착 때 한마디)입니다.
- **검증**: 에뮬레이터

### 2-7. 일기 한 장 (주차 후)

- **사용법**: 주차하면 자동으로 뜹니다. 왼쪽은 차가 본 것, 오른쪽은 나. 질문은 한 번에 하나만 나옵니다: 지난번보다 어땠는지 → 들은 한마디가 도움이 됐는지 → 이곳의 이름 → 오늘 한 줄. 바쁘면 "나중에 할게요". 답하지 않은 일기는 홈의 "돌아볼 일기"에 남습니다. 아래로 내리면 지나온 길, 오늘의 숫자, 주행 타임라인, 다음으로가 있습니다.
- **파이프라인**: `Trip.end` → `Writer.write` → `Store.addDiary` → `diaryScreen` → `diaryPage`(`Arrival.kt`) → 답은 `Store.setAnswer` / `setFeeling`.
- **검증**: 테스트(화면)

### 2-8. 같은 길에서 늘었는지

- **사용법**: 같은 목적지에 세 번째 다녀온 날부터 "늘었어요 / 비슷해요 / 쉽지 않았어요"가 나옵니다. 두 번째 날에는 달라진 값만 보여 줍니다. "왜 이렇게 판단했나요"를 누르면 근거가 나옵니다. 일기장에서 길 칩을 고르고 "‘회사’에서 내가 늘었는지 보기"를 누르면 그래프가 나옵니다.
- **파이프라인**: `Growth.judge`(같은 곳의 끝까지 다녀온 실제 주행만, 처음 세 번의 평균과 비교) → `judgementView` → `roadScreen` 그래프.
- **규칙**: 내가 정할 수 있는 습관만 판정에 씁니다(돌기 전 깜빡이, 차선 변경 3초 전 깜빡이, 급하게 선 횟수, 재탐색, 주차). 연비는 가볍게. 차선 변경 전 기다린 시간·브레이크 횟수·걸린 시간은 참고만.
- **검증**: 테스트(`GrowthTest` 8개)

### 2-9. 첫 주행과 처음 가는 길

- **사용법**: 따로 할 일 없음. 견줄 지난번이 없는 날은 일기에 "오늘 차가 본 것"이 나옵니다.
- **파이프라인**: `Coach.about` / `Coach.today` → `carSawCard`. 평소의 나는 `Coach.usual`(최근 실제 주행 5번, 모의 주행과 예시 기록 제외).
- **규칙**: 습관은 평소의 나와, 주차는 같은 자리의 지난번과만 견줍니다. 평소 대비 말은 회전이 3번 넘게 쌓였을 때부터 나옵니다.
- **검증**: 에뮬레이터

### 2-10. 다음에 들을 한마디

- **사용법**: 일기 한 장의 "다음에 들을 한마디 남기기"를 누르면 차가 본 순간(급하게 선 곳, 오래 기다린 차선 변경, 재탐색)마다 문장 후보가 나옵니다. 고르거나 고쳐 씁니다. 다음에 같은 곳에 갈 때 홈 "다시 갈 길"에서 그곳을 고르면 출발 전에 보여 주고, 그 자리 150m 안에서 소리로 들려줍니다. 후보 문장은 정해진 규칙으로 만듭니다(생성형 AI 아님).
- **파이프라인**: `TipSuggest` → `keepForNextTime` → `Store.addGuide` → 홈 `againCard` → `depart` → `Trip.tipsNear`(거리·진행 방향) + FusedLocation `addProximityAlert` → 음성.
- **조건**: 위치 사용에 동의해야 하고, 그곳에 이름과 좌표가 있어야 합니다(내비 목적지이거나 주차 후 이름을 붙인 곳).
- **검증**: 테스트(모의 주행에서 재생) · 에뮬레이터(실제 위치에서)

### 2-11. 차에게 물어보기

- **사용법**
  - 버튼: 주행 화면에서 **멈춰 있을 때** 오른쪽의 "지금까지 어땠어?" (넓은 창에만 있습니다).
  - 말: 글레오에게 "차곡차곡, 오늘 차선 변경 어땠어?" 주제는 전체 · 차선 변경 · 깜빡이 · 주차 · 브레이크.
- **파이프라인**: 버튼 → `Coach.askCar` → 음성과 화면. 글레오 → `GleoReceiver`의 `ASK_MY_DRIVING` → 앱이 직접 읽어 줌(소리를 꺼 두었으면 답을 글레오에게 넘김).
- **글레오에 열어 둔 기능 세 가지**: `ASK_MY_DRIVING`(내 운전 물어보기), `SAVE_NOTE_HERE`(여기 한마디 남기기), `TAKE_IT_SLOW`(여기 어려웠어).
- **검증**: 에뮬레이터(글레오가 앱을 부르는지)

### 2-12. 내비

- **사용법**: 홈 "내비 열기" → 어디로 갈지 입력 → 내비의 장소 검색으로 넘어갑니다. "다시 갈 길"의 줄을 누르면 그 목적지를 내비에 보냅니다.
- **파이프라인**: `findInNavi` → `showNavi` → 내비 앱 실행 + NaviHelper `requestNavigationScreen`. 목적지 보내기는 `Car.requestRoute`.
- **화면 나누기**: 내비를 "옆 창에" 띄워 달라고 부탁합니다(안드로이드 표준 방식). 받아 줄지는 차가 정하므로, 받아 주지 않으면 내비가 앱 영역을 다 씁니다.
- **검증**: 에뮬레이터(내비가 앞으로 오는지)

### 2-13. 일기장

- **사용법**: 하루가 한 면입니다. 맨 위 줄에 그날 요약(주행 횟수, 거리, 깜빡이, 차선 변경, 급하게 선 것), 아래에 주행마다 한 줄. 위의 칩으로 길을 고릅니다.
- **검증**: 테스트(화면)

### 2-14. 설정

| 항목 | 하는 일 |
|---|---|
| 소리로 알려 주기 | 끄면 말 대신 화면 알림 |
| 말 거는 정도 | 자주(깜빡이 안내와 칭찬까지) / 필요할 때만(남겨 둔 한마디와 경고만) |
| 한마디를 남긴 곳 근처에서 듣기 | 위치 사용. 운전자마다 따로 동의 |
| 도착지 날씨 | 목적지 좌표를 약 1km 단위로 줄여 공개 예보로 보냄 |
| 차량 연결 상태 | 차량·내비·위치·음성 연결과 실제로 받은 신호. 시연으로 만든 신호는 세지 않음 |
| 권한 다시 묻기 | 위치·속도·알림 권한을 지움. 앱을 완전히 껐다 켜면 다시 물어봄 |
| 기록 모두 지우기 | 일기, 길, 설정이 이 차에서 지워짐 |

### 2-15. 시연 (시연판에만 있음)

- **출근길 시연 보기**: 설정 › 시연 › 출근길 시연 보기 → **모의 주행 시작 (시연용)** → 약 90초 뒤 도착 → 기어 P(또는 "기록 끝내기") → 일기에서 "늘었어요".
- 지난 출근 세 번은 예시 기록, 오늘은 모의 주행입니다. 화면에 "예시"·"시연용"으로 표시되고, 모의 주행이 만든 신호는 "받은 신호"에 세지 않습니다.
- 정식판(`market`) 빌드에는 들어가지 않습니다.
- **검증**: 테스트(끝까지 돌려 "늘었어요" 확인)

### 2-16. 달리는 중의 화면 제한

- 기록 중이거나 차가 주행 제한을 걸면 주행 화면 하나만 보입니다. 일기·일기장·설정은 열리지 않습니다.
- 차가 굴러가는 중(주행 제한 신호, 또는 속도 시속 5km 이상)에는 주행 화면의 버튼도 잠깁니다. 글자 입력은 기록 중 내내 막습니다.
- **검증**: 에뮬레이터

## 4. 고친 것

| 문제 | 고친 방법 |
|---|---|
| 판정 문장이 "돌기 전 깜빡이이 58% → 100%"로 나옴 | 조사를 빼고 "돌기 전 깜빡이 58% → 100%"로 |
| 조건이 다른 날에는 근거 시트의 ±10% 줄이 사라짐 | 식의 묶음 순서를 바로잡음 |
| 받은 길 없이 달리면 급하게 선 곳·차선 변경의 위치가 적히지 않음 | 위치가 올 때마다 기억하도록 |
| 돌아볼 순간이 두 개 넘으면 홈 "돌아볼 일기"가 사라지지 않음 | 순간은 숙제로 세지 않음. 질문에 답하면 사라짐 |
| 첫 기어 값이 P면 "기어 신호를 받지 못했어요"로 남음 | 첫 값도 화면에 알림. 홈은 기어·벨트가 바뀌면 다시 그림 |
| 벨트 신호가 없는 차에서도 "안전벨트를 매 주세요" | 신호를 받은 차에서만 보임 |
| 소리를 꺼 두면 글레오 질문에 답이 없음 | 답을 글레오에게 넘김 |
| 말로 남긴 한마디가 일기에 "옆자리에서…"로 적힘 | "달리면서 …라고 말로 남겼다"로 |
| "말 거는 정도"가 세 단계처럼 보이지만 실제로는 두 단계 | 두 단계로 |
| 차가 주행 제한을 걸지 않으면 달리는 중에도 버튼이 눌림 | 속도 시속 5km 이상이면 잠금 |
| 평소의 나에 예시 기록이 섞임 | 예시 기록을 뺌 |
| 개인정보 안내가 사실과 다름(없는 설정, 빠진 신호) | 지금 쓰는 신호와 밖으로 나가는 것을 그대로 적음 |
| "김현대의 한마디"처럼 내 메모를 남의 것처럼 부름 | 내 길이면 "내 한마디", "지난번에 다녀온 길" |
| 일기가 한 장(또는 홀수 장)이면 일기장에 마지막 카드가 보이지 않음 | 두 칸 격자의 빈 칸이 줄 높이를 1px로 줄이던 것을 고침 |
| 모의 주행을 중간에 끝내도 "끝까지 달림"으로 세어 판정이 나옴 | 모의 주행도 도착해야 판정함 |
| 예시 기록만으로 그린 "이 길의 나"가 내 기록처럼 보임 | 화면 위에 "예시 기록 포함"과 개수를 밝힘 |
| 다녀온 곳이 많아지면 일기장 위쪽 칩이 넘침 | 자주 간 네 곳만 보이고 나머지는 "다른 곳"에서 고름 |
| 자세한 기록(지나온 길·오늘의 숫자)이 일기 아래에 잘려 보임 | 일기 한 장이 화면을 채우고, 자세한 기록은 단추로 엶 |
| 좁은 창(내비 옆)에 "지금까지 어땠어?"가 없음 | 좁은 창에도 넣고 주행 화면이 한 화면에 들어오게 함 |

## 5. 알려진 한계

- **끝까지 갔는지의 기준이 길 종류마다 다릅니다.** 내비 목적지로 간 주행은 중간에 끝내도 그 길의 기록으로 셉니다. 내가 남긴 한마디가 있는 길은 도착 신호나 거리 90%가 없으면 끝까지 간 것으로 치지 않습니다.
- **글레오로 남긴 한마디는 목적지 이름이 없으면 다음에 들려줄 수 없습니다.** 이름 없는 곳에 남긴 한마디도 홈 목록에 나오지 않습니다.
- **앱이 꺼졌다 이어 쓸 때** 신경 쓰이는 것과 사건의 위치가 복원되지 않습니다.
- **예시 기록**은 "다시 갈 길"과 일기 수에는 여전히 함께 셉니다(화면에 "예시" 표시).
- **출근길 시연의 숫자는 시간대에 따라 조금 달라집니다.** 출근 시간대(6~10시)에 돌리면 58%가 아니라 60% → 100%로 나옵니다(조건이 다른 기록을 절반만 반영하는 규칙 때문).
- 화면에서 덜어 낸 기능의 코드(법규, 기어 안내, 성장 바, 함께 차곡 등)가 남아 있습니다.
