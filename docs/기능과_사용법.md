# 차곡차곡 – 기능과 사용법

> **차로 쓰는 성장일기.** 내 운전을 아는 차가 달리는 동안 말을 걸어 주고, 같은 길에서 내가 늘었는지 보여 준다.

## 1. 한눈에 보는 사용법

| 언제 | 내가 하는 일 | 차(앱)가 하는 일 |
|---|---|---|
| 처음 켰을 때 | 이름, 운전자 종류(지금은 운전 초보), 위치·소리 고르기. 권한 창에서 위치·속도·알림 허락 | 첫 인사 |
| 출발 전 (선택) | 홈에서 "요즘 제일 신경 쓰이는 것" 고르기 | 그것부터 말해 줄 준비 |
| 출발 | 기어를 **D**에 놓는다. 누를 것은 없다 | 기록 시작, "출발해요" |
| 달리는 동안 | 운전만 한다 | 돌기 전에 깜빡이 안내, 차선 변경을 마치면 한마디, 남겨 둔 한마디를 그 자리에서 |
| 궁금할 때 (선택) | "지금까지 어땠어?" 누르기, 또는 글레오에게 묻기 | 지금까지 기록으로 답함 (달리는 중에는 말로만) |
| 도착 | 완전히 멈춘 뒤 기어를 **P**에 놓는다 | 일기 한 장을 만들고 한 줄 말해 줌 |
| 주차 후 | 질문에 답하고(한 번에 하나), 다음에 들을 한마디 남기기 | 차가 본 것과 내 답을 합쳐 보여 줌 |
| 다시 갈 때 | 홈 "다시 갈 길"에서 고르고 D | 지난번 한마디를 그 근처에서 들려줌 |
| 쌓이면 | 일기장에서 길을 고름 | 같은 길에서 늘었는지 판단하고 그래프로 |

---

## 2. 기능과 사용법

### 2-1. 기록 시작과 끝

- 기어를 D에 놓으면 시작, P에 놓으면 끝. 홈 맨 위 카드는 지금 차 상태(안전벨트, 연료·배터리, 내비 목적지)를 보여 주는 것이고, 기어 신호를 못 받는 차에서만 눌러서 시작합니다.

### 2-2. 속도와 급하게 선 순간

- 권한 창에서 **속도**를 허락해야 합니다. 허락하지 않으면 급정거 없이 기록합니다.

### 2-3. 돌기 전 깜빡이

- 내비가 회전을 안내하는 중이어야 합니다. 회전이 가까운데 깜빡이가 꺼져 있으면 "지금 오른쪽 깜빡이"라고 말하고 화면에 보여 줍니다. 미리 켰으면 짧게 칭찬합니다.

### 2-4. 차선 변경

- 깜빡이를 켜고 → 기다렸다가 → 운전대를 조금 돌려 넘어가고 → 깜빡이를 끕니다. 깜빡이를 켜고 3초 넘게 지난 뒤 넘어갔으면 끄는 순간 "깜빡이 켜고 n초, 잘 넘어갔어요"라고 말합니다(한 주행에 세 번까지, 차선 변경을 신경 쓰인다고 골랐으면 다섯 번까지).

### 2-5. 안전벨트

- 벨트를 안 맨 채 출발하면 말과 주행 화면 맨 위로 20초 동안 알려 줍니다.
- 가상 콘솔에는 안전벨트 조작이 없어 에뮬레이터에서는 늘 "안 맴"으로 나옵니다. 시연판에서는 주행 화면의 **안전벨트 맸어요 (시연)** 을 누르면 넘어갑니다.

### 2-7. 일기 한 장 (주차 후)

- 주차하면 자동으로 뜹니다. 왼쪽은 차가 본 것, 오른쪽은 나. 질문은 한 번에 하나만 나옵니다: 지난번보다 어땠는지 → 들은 한마디가 도움이 됐는지 → 이곳의 이름 → 오늘 한 줄. 바쁘면 "나중에 할게요". 답하지 않은 일기는 홈의 "돌아볼 일기"에 남습니다. 아래로 내리면 지나온 길, 오늘의 숫자, 주행 타임라인, 다음으로가 있습니다.

### 2-8. 같은 길에서 늘었는지

- 같은 목적지에 세 번째 다녀온 날부터 "늘었어요 / 비슷해요 / 쉽지 않았어요"가 나옵니다. 두 번째 날에는 달라진 값만 보여 줍니다. "왜 이렇게 판단했나요"를 누르면 근거가 나옵니다. 일기장에서 길 칩을 고르고 "‘회사’에서 내가 늘었는지 보기"를 누르면 그래프가 나옵니다.

### 2-9. 첫 주행과 처음 가는 길

- 지난번이 없는 날은 일기에 "오늘 차가 본 것"이 나옵니다.

### 2-10. 다음에 들을 한마디

- 일기 한 장의 "다음에 들을 한마디 남기기"를 누르면 차가 본 순간(급하게 선 곳, 오래 기다린 차선 변경, 재탐색)마다 문장 후보가 나옵니다. 고르거나 고쳐 씁니다. 다음에 같은 곳에 갈 때 홈 "다시 갈 길"에서 그곳을 고르면 출발 전에 보여 주고, 그 자리 150m 안에서 소리로 들려줍니다. 후보 문장은 정해진 규칙으로 만듭니다

### 2-11. 차에게 물어보기

- **사용법**
  - 버튼: 주행 화면 아래의 "지금까지 어땠어?". 멈춰 있을 때는 답을 화면에도 보여 주고, 달리는 중에는 말로만 답합니다.
  - 말: 글레오에게 "차곡차곡, 오늘 차선 변경 어땠어?" 주제는 전체 · 차선 변경 · 깜빡이 · 주차 · 브레이크.

### 2-12. 내비

- 홈 "내비 열기" → 어디로 갈지 입력 → 내비의 장소 검색으로 넘어갑니다. "다시 갈 길"의 줄을 누르면 그 목적지를 내비에 보냅니다.

### 2-13. 일기장

- 맨 위 줄에 그날 요약(주행 횟수, 거리, 깜빡이, 차선 변경, 급하게 선 것), 아래에 주행마다 한 줄. 위의 뱃지으로 길을 고릅니다.

### 2-14. 설정

| 항목 | 하는 일 |
|---|---|
| 소리로 알려 주기 | 끄면 말 대신 화면 알림 |
| 말 거는 정도 | 자주(깜빡이 안내와 칭찬까지) / 필요할 때만(남겨 둔 한마디와 경고만) |
| 한마디를 남긴 곳 근처에서 듣기 | 위치 사용. 운전자마다 따로 동의 |
| 도착지 날씨 | 목적지 좌표를 약 1km 단위로 줄여 공개 예보로 보냄 |
| 차량 연결 상태 | 차량·내비·위치·음성 연결과 실제로 받은 신호. 시연으로 만든 신호는 세지 않음 |
| 권한 다시 묻기 | 위치·속도·알림 권한을 지움. 앱을 완전히 껐다 켜면 다시 물어봄 |
| 기록 모두 지우기 | 일기, 길, 설정이 이 차에서 지워짐 |

### 2-15. 시연 (시연판에만 있음)

- **출근길 시연 보기**: 설정 › 시연 › 출근길 시연 보기 → **모의 주행 시작 (시연용)** → 약 90초 뒤 도착 → 기어 P(또는 "기록 끝내기") → 일기에서 "늘었어요".
- 지난 출근 세 번은 예시 기록, 오늘은 모의 주행입니다. 화면에 "예시"·"시연용"으로 표시되고, 모의 주행이 만든 신호는 "받은 신호"에 세지 않습니다.

### 2-16. 달리는 중의 화면 제한

- 기록 중이거나 차가 주행 제한을 걸면 주행 화면 하나만 보입니다. 일기·일기장·설정은 열리지 않습니다.
- 차가 굴러가는 중(주행 제한 신호, 또는 속도 시속 1km 이상)에는 창을 띄우지 않습니다. "지금까지 어땠어?"는 한 번 누르면 말로만 답하고, "기록 끝내기"는 기어를 P에 놓고 멈추면 끝난다고 말해 줍니다. 글자 입력은 기록 중 내내 막습니다.

## 3. 가상 콘솔로 직접 달려 보기

[시연 가이드](시연가이드.md)의 B에 순서가 있습니다. 요약:

1. 권한 허락(속도 포함) → 기어 D → ACCEL로 시속 40km, 20초 넘게.
2. Steering을 한 번 살짝 움직였다 0 → Turn Signal Blink left → 4~5초 → Steering 10~20° → 0 → Off.
3. BRAKE로 멈춘 뒤 P.

## 5. 현재 한계

- **끝까지 갔는지의 기준이 길 종류마다 다릅니다.** 내비 목적지로 간 주행은 중간에 끝내도 그 길의 기록으로 셉니다. 내가 남긴 한마디가 있는 길은 도착 신호나 거리 90%가 없으면 끝까지 간 것으로 치지 않습니다.
- **글레오로 남긴 한마디는 목적지 이름이 없으면 다음에 들려줄 수 없습니다.** 이름 없는 곳에 남긴 한마디도 홈 목록에 나오지 않습니다.
- **앱이 꺼졌다 이어 쓸 때** 사건의 위치가 복원되지 않습니다.
- **예시 기록**은 "다시 갈 길"과 일기 수에는 여전히 함께 셉니다(화면에 "예시" 표시).
- **출근길 시연의 숫자는 시간대에 따라 조금 달라집니다.** 출근 시간대(6~10시)에 돌리면 58%가 아니라 60% → 100%로 나옵니다.
