# 차곡차곡 시연 가이드

> **차가 내 운전을 기억했다가, 같은 길을 다시 달릴 때 내가 늘었다는 걸 보여 준다.**

앱이 하는 일은 네 단계입니다. 시연도 이 순서를 그대로 따라갑니다.

| 단계 | 화면 | 쓰는 Pleos SDK·API |
|---|---|---|
| ① D · 차가 기억해요 | 주행 화면 (하나만 보이는 화면) | Vehicle SDK(깜빡이·브레이크·조향각·연비), AAOS 기어, NaviHelper(회전 안내·재탐색) |
| ② P · 돌아봐요 | 주차 후 "이 길을 돌아봐요" | FusedLocation(그 순간의 위치), 앱 안 분석 |
| ③ 다시 갈 때 · 그 근처에서 | 출발 전 "이번에 참고할 지난번 한마디", 주행 중 음성 | FusedLocation `addProximityAlert`, TextToSpeech, 오디오 포커스 |
| ④ 늘었는지 · 차와 내가 함께 | 차가 본 변화 + 내 느낌, "이 길의 나" 그래프 | 앱 안 분석 (규칙 공개) |

---

## A. 2분 시연 (공모전판, 위치 재생 없이)

에뮬레이터에서 위치가 움직이지 않아도 네 단계를 끝까지 보여 줍니다. 지난 출근 세 번은 **예시 기록**, 네 번째 출근은 **모의 주행**이며 화면에 모두 그렇게 표시됩니다.

1. 설정 › 연결 › **차량 연결 상태** › 시연 도구 › **시연: 회사 가는 길, 네 번째 출근**
   - 위치 동의를 물으면 "동의해요".
   - 출발 전 화면에 **"이번에 참고할 지난번 한마디 1개"**가 보입니다: "곧 합류 구간이야. 미리 차선을 옮겨 두자."
2. **모의 주행 (시연용)**을 누릅니다 (약 90초).
   - 돌기 전에 깜빡이가 켜지고, 합류 400m 앞에서 **"내 한마디. 곧 합류 구간이야…"**를 소리로 들려줍니다.
   - 합류 구간에서 깜빡이를 켜고 **6초** 만에 차선을 바꿉니다 (지난번 12~15초).
   - 이때 **내비로 전환했다가 돌아와도** 상단에 "모의 주행 기록 중"이 그대로 있고, 알림에 "차곡차곡 기록 중"이 보입니다.
3. 도착하면 Virtual Console에서 **기어 P** (또는 "기록 끝내기").
4. 주차 후 **"이 길을 돌아봐요"**
   - 맨 위에 **차가 본 변화 · 늘었어요**가 큰 숫자로 보입니다: 차선 변경 전 기다림 13초 → 6초(−54%), 돌기 전 깜빡이 58% → 100%(+42%p)
   - "왜 이렇게 판단했나요" → 지표별 기준·오늘·무게와 규칙
   - 내 느낌은 어땠어요? → "더 편했어요" → **"차도 나도 늘었다고 말해요"**, 성장 바 차곡차곡 단계에 칸이 쌓입니다
   - 길 위에서 들은 한마디, 도움이 됐나요? → "도움이 됐어요"
5. 일기의 **"이 길의 나 · 그래프로 보기"**: 네 번의 출근이 지표별 선 그래프로 보입니다 (점선은 처음 세 번의 평균, 비 온 날 표시).
6. 끝나면 시연 도구 › **시연 기록 지우기**.

## B. 실제 위치로 시연 (경로 재생 두 번)

1. 내비에 목적지를 넣고, 에뮬레이터 ⋯ › Location › Routes에서 `tools/예시길.gpx`를 재생합니다.
2. Virtual Console: 기어 D → 가는 길 중간에 브레이크 3번, 깜빡이 → 기어 P.
3. "이 길을 돌아봐요"에서 **"브레이크를 3번 밟은 구간이에요"** → 돌아보기 → 추천 문장을 고르거나 고쳐 써서 남깁니다.
4. 홈 **"다시 가 볼까요?"**에서 그곳을 고르고, 같은 경로를 다시 재생 → D.
5. 남긴 곳 근처에서 소리로 들려줍니다 → P → 차가 본 변화와 내 느낌.

※ 조향각을 Virtual Console에서 바꿀 수 없으면 차선 변경은 시연 도구 › 시험용 신호 › "차선 변경"으로 보여 줍니다 (화면에 시험용 표시).

## 시연 영상 대본 (약 2분 30초, 화면 녹화)

| 시간 | 화면 | 말 (자막) |
|---|---|---|
| 0:00 | 첫 화면 네 단계 | "운전은 같은 길을 다시 달릴 때 늘어요. 차곡차곡은 차가 내 운전을 기억했다가, 같은 길을 다시 달릴 때 내가 늘었다는 걸 보여 줘요." |
| 0:15 | 홈 | "다녀온 곳과 지난번에 남긴 한마디가 먼저 보여요. 오늘은 네 번째 출근이에요." |
| 0:25 | 출발 전 | "지난번 합류 구간에서 깜빡이를 켜고 12초를 기다렸어요. 그때 남긴 말이 '미리 차선을 옮겨 두자'예요." |
| 0:40 | 모의 주행 시작, 내비 옆 화면 | "달리는 동안 화면은 하나만 보여요. 나머지는 말로." |
| 0:55 | 한마디 재생 | "합류 400m 앞에서, 지난번의 내가 남긴 말을 들려줘요." |
| 1:10 | 내비로 전환 → 복귀 | "내비를 크게 띄워도 기록은 계속돼요." |

| 1:40 | 근거 시트 | "판단 규칙은 공개해요. 습관 지표는 무겁게, 길 상황에 흔들리는 지표는 가볍게." |

## 2차 PT 예상 질문

| 질문 | 답 |
|---|---|
| 기록 비교는 다른 앱에도 있지 않나요? | 비교 자체가 아니라 **지난 경험이 다음 운전에 도움이 되는 순간**에 집중합니다. 차가 본 순간을 운전자가 해석해 남기고, 다음에 그 근처에서 소리로 들려주고, 도움이 됐는지 확인합니다. |
| 늘었다는 판단을 믿을 수 있나요? | 규칙을 공개합니다. 지난 기록이 두 번 이상일 때만 판단하고, 같은 길·끝까지 다녀온 실제 주행만, 처음 세 번 평균과 비교, 조건(시간대·비·밤)이 다르면 절반만 반영, 걸린 시간은 판단에서 뺍니다. 운전자의 느낌과 합쳐 최종 평가를 냅니다. |
| 차선 변경 때 옆 차 속도·거리를 알려 주면 좋지 않나요? | 인터뷰에서 가장 많이 나온 요구입니다. 공개 SDK에 주변 차량 데이터가 없고, 실시간 판단은 제조사가 검증하는 안전 기능이라 앱은 **그 순간에는 말하지 않고**, 지난 기록으로 그 구간 전에 미리 준비시킵니다. 드라이빙 뷰에 후측방 센서 정보를 보여 주는 것은 플랫폼 제안으로 정리했습니다. |
| 차선 변경은 어떻게 알아내나요? | 깜빡이 + 조향각(Vehicle SDK)으로 추정합니다. 내비가 300m 안의 회전을 안내 중이거나 조향이 30°를 넘으면 회전으로 보고 뺍니다. 화면에 "추정"이라고 밝힙니다. |
| 앱을 안 켜면 기록이 안 되나요? | 앱이 한 번 켜져 있으면 D에서 저절로 시작하고, 기록 중에는 앞쪽 서비스(알림)로 내비 전체 화면·앱 전환에도 유지됩니다. |
| 운전 중 위험하지 않나요? | 주행 제한(CarUxRestrictions)을 따르고, 신호를 못 받으면 기어로, 기어도 모르면 주행 중으로 판단합니다. 음성은 우선순위·중복 제거·때 지난 말 버리기를 지킵니다. |
