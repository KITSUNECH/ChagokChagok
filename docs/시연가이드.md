# 차곡차곡 시연 가이드

> **차로 쓰는 성장일기.** 내 운전을 아는 차가 달리는 동안 말을 걸어 주고, 같은 길에서 내가 늘었는지 보여 준다.

시연은 운전의 흐름을 그대로 따라갑니다.

| 순서 | 화면 | 쓰는 Pleos SDK·API |
|---|---|---|
| 달리는 동안 | 주행 화면 (지금 필요한 것 하나) | Vehicle SDK(깜빡이·브레이크·조향각·연비), AAOS 기어, NaviHelper(회전 안내·재탐색), TextToSpeech |
| 주차하면 | 일기 한 장: 차가 본 것 + 나 | Vehicle SDK 기록, 앱 안 분석 |
| 다시 갈 때 | 출발 전 지난번 한마디, 그 자리에서 음성 | FusedLocation `addProximityAlert`, TextToSpeech, 오디오 포커스 |
| 쌓이면 | 이 길의 나 그래프 | 앱 안 분석 (규칙 공개) |
| 물어보면 | 차에게 물어보기 / 글레오 | Gleo AI App Integration, TextToSpeech |

## A. 2분 시연 (공모전판, 위치 재생 없이)

에뮬레이터에서 위치가 움직이지 않아도 끝까지 보여 줍니다. 지난 출근 세 번은 **예시 기록**, 오늘 출근은 **모의 주행**이며 화면에 모두 그렇게 표시됩니다. 모의 주행이 만든 신호는 "받은 신호"에 세지 않고 따로 셉니다.

0. (선택) 홈의 **요즘 제일 신경 쓰이는 건?** 에서 "차선 변경"을 고릅니다. 달리는 동안과 주차 후에 그것부터 말해 줍니다.
1. 설정 › 시연 › **출근길 시연 보기**
   - 위치 동의를 물으면 "동의해요".
   - 출발 전 화면에 **"이번에 참고할 지난번 한마디 1개"**가 보입니다: "곧 합류 구간이야. 미리 차선을 옮겨 두자."
2. **모의 주행 (시연용)**을 누릅니다 (약 90초).
   - 돌기 전에 깜빡이가 켜지고, 합류 400m 앞에서 **"내 한마디. 곧 합류 구간이야…"**를 소리로 들려줍니다.
   - 합류 구간에서 깜빡이를 켜고 **6초** 만에 차선을 바꿉니다 (지난번 12~15초). 마치면 **"깜빡이 켜고 6초, 잘 넘어갔어요."**
   - 이때 **내비로 전환했다가 돌아와도** 상단에 "모의 주행 기록 중"이 그대로 있고, 알림에 "차곡차곡 기록 중"이 보입니다.
   - 멈춰 있는 동안 오른쪽의 **지금까지 어땠어?** 를 누르면 지금까지의 기록으로 바로 답합니다.
3. 도착하면 Virtual Console에서 **기어 P** (또는 "기록 끝내기").
4. **일기 한 장**이 스크롤 없이 한 화면에 나옵니다.
   - 왼쪽 **차가 본 변화 · 늘었어요**: 차선 변경 전 기다림 13초 → 6초(−54%), 돌기 전 깜빡이 58% → 100%(+42%p)
   - "왜 이렇게 판단했나요" → 지표별 기준·오늘·무게와 규칙
   - 오른쪽 질문은 한 번에 하나: 내 느낌은 어땠어요? → "더 편했어요" → **"차도 나도 늘었다고 말해요"** → 들은 한마디가 도움이 됐나요? → 오늘 한 줄
   - 아래로 내리면 지나온 길 그림, 타임라인, 기록의 근거
5. 일기장 › 길별 › **회사**: 네 번의 출근이 지표별 선 그래프로 보입니다 (점선은 처음 세 번의 평균, 비 온 날 표시).
6. 끝나면 설정 › 시연 › 시연 도구 › **시연 기록 지우기**.

## B. 가상 콘솔로 직접 달려 보기 (모의 주행 없이)

Virtual Console(`http://127.0.0.1:8088/`)이 실제로 보내는 신호만으로 기록을 만듭니다. 아래에서 "Emulation Controls"는 콘솔 왼쪽 아래의 단추를 누르면 열리는 목록입니다.

1. 앱을 켜고 권한 창에서 **위치·속도·알림**을 허락합니다 (속도를 허락해야 급하게 선 순간이 적힙니다).
2. 콘솔에서 기어 **D**. 앱이 주행 화면으로 바뀌고 "출발해요"라고 말합니다.
3. **ACCEL**을 누르고 있으면 속도가 오릅니다. 시속 40km쯤까지 올립니다.
4. 깜빡이: Emulation Controls › **Turn Signal State** › Blink left (또는 right). 끌 때는 Off.
5. 차선 변경 한 번: (D에 놓은 뒤 처음이라면 **Steering** 막대를 한 번 살짝 움직였다 0으로 돌려 조향각 신호를 먼저 보냅니다) → Blink left → 4~5초 기다림 → Steering 막대를 10~20°로 돌렸다가 0으로 → Turn Signal Off. 깜빡이를 끄는 순간 앱이 "깜빡이 켜고 n초, 잘 넘어갔어요"라고 말합니다. 30°를 넘기면 교차로 회전으로 보고 세지 않습니다.
6. 급하게 서기: 시속 40km 넘게 달리다 **BRAKE**를 끝까지 누르고 있습니다.
7. 속도가 0이 되면 기어 **P**. 일기 한 장이 생깁니다. 브레이크 줄에 "급하게 섰어요", 차선 변경 줄에 기다린 시간이 나옵니다.
8. 같은 순서를 한 번 더 하면 "평소의 나"와 견준 말이 나옵니다.

알아 둘 것:
- **안전벨트는 가상 콘솔에 조작 단추가 없습니다.** 앱은 "안전벨트를 매 주세요"를 출발하고 20초 동안만 보여 주고 물러납니다.
- **D에 놓았다가 움직이지 않고 P로 돌아오면** 일기를 만들지 않고 "움직이지 않아서 일기로 남기지 않았어요"라고 말합니다.
- **내비의 회전 안내와 위치**는 가상 콘솔이 만들지 않습니다. 위치는 에뮬레이터 ⋯ › Location › Routes에서 `tools/예시길.gpx`를 재생하고, 회전 안내는 내비 앱에서 목적지를 넣고 안내를 시작해야 들어옵니다. 내비가 재생 중인 위치를 따라 안내하는지는 확인하지 못했습니다.
- "같은 길에서 늘었어요"까지 보려면 같은 목적지로 세 번 넘게 다녀와야 합니다. 그래서 시연에서는 A의 예시 기록과 모의 주행을 씁니다.

## 2차 PT 예상 질문

| 질문 | 답 |
|---|---|
| 기록 비교는 다른 앱에도 있지 않나요? | 비교 자체가 아니라 **지난 경험이 다음 운전에 도움이 되는 순간**에 집중합니다. 차가 본 순간을 운전자가 해석해 남기고, 다음에 그 근처에서 소리로 들려주고, 도움이 됐는지 확인합니다. |
| 늘었다는 판단을 믿을 수 있나요? | 규칙을 공개합니다. 지난 기록이 두 번 이상일 때만 판단하고, 같은 길·끝까지 다녀온 실제 주행만, 처음 세 번 평균과 비교, 조건(시간대·비·밤)이 다르면 절반만 반영, 걸린 시간은 판단에서 뺍니다. 운전자의 느낌과 합쳐 최종 평가를 냅니다. |
| 차선 변경 때 옆 차 속도·거리를 알려 주면 좋지 않나요? | 인터뷰에서 가장 많이 나온 요구입니다. 공개 SDK에 주변 차량 데이터가 없고, 실시간 판단은 제조사가 검증하는 안전 기능이라 앱은 **그 순간에는 말하지 않고**, 지난 기록으로 그 구간 전에 미리 준비시킵니다. 드라이빙 뷰에 후측방 센서 정보를 보여 주는 것은 플랫폼 제안으로 정리했습니다. |
| 차선 변경은 어떻게 알아내나요? | 깜빡이 + 조향각(Vehicle SDK)으로 추정합니다. 내비가 300m 안의 회전을 안내 중이거나 조향이 30°를 넘으면 회전으로 보고 뺍니다. 화면에 "추정"이라고 밝힙니다. |
| 익숙해지면 안 쓰게 되지 않나요? | 길 하나는 졸업해도 운전은 계속 달라집니다. 같은 길도 첫 빗길·첫 밤길은 다시 초행이고, 익숙해진 길은 같은 차를 쓰는 가족에게 건넬 수 있습니다. 사람은 졸업해도 차와 가족 단위로는 계속 쓰입니다. |
| 처음 쓰는 날에는 견줄 게 없지 않나요? | 견주는 데는 지난 기록이 필요하지만 말을 거는 데는 필요 없습니다. 첫날은 오늘 본 사실을 그대로 적고 기준으로 삼습니다. 두 번째 주행부터는 평소의 나와, 같은 길 두 번째부터는 그 길의 지난번과 견줍니다. |
| 앱을 안 켜면 기록이 안 되나요? | 앱이 한 번 켜져 있으면 D에서 저절로 시작하고, 기록 중에는 앞쪽 서비스(알림)로 내비 전체 화면·앱 전환에도 유지됩니다. |
| 운전 중 위험하지 않나요? | 주행 제한(CarUxRestrictions)을 따르고, 신호를 못 받으면 기어로, 기어도 모르면 주행 중으로 판단합니다. 음성은 우선순위·중복 제거·때 지난 말 버리기를 지킵니다. |

## 에뮬레이터에서 꼭 확인할 것 (제출 전)

- [ ] 첫 실행: 시작 모션(흰 테두리가 아래에서부터 쌓임) → 첫 설정 4단계 → 위치 동의
- [ ] A. 2분 시연이 끝까지 (한마디 재생, 차선 변경 기록, 늘었어요, 그래프)
- [ ] 모의 주행 중 내비로 전환 → 복귀 시 기록 유지, 알림 "차곡차곡 기록 중"
- [ ] 내비 옆 분할 화면에서 글자·버튼이 잘리지 않는지
- [ ] 글레오: "차곡차곡, 오늘 차선 변경 어땠어" / "차곡차곡, 여기 어려웠어" / "차곡차곡, 여기 한마디 남겨 줘" (글레오가 앱을 부르는지, 앱이 소리로 답하는지)
- [ ] 주행 화면(멈췄을 때)의 "지금까지 어땠어?" 버튼이 소리로 답하는지
- [ ] 기어 P에서 홈의 맨 위 카드를 누르면 기록이 시작되지 않고 "기어를 D에 놓으면 기록을 시작해요"라고 말하는지, D에서 시작하는지
- [ ] 안전벨트를 안 맨 채 D에 놓으면 화면과 말로 알려 주고, 매면 사라지는지
- [ ] 속도 권한을 허락한 뒤 Virtual Console에서 속도를 빠르게 내리면 일기의 브레이크 줄에 "급하게 섰어요"가 나오는지
- [ ] 홈과 일기 한 장이 스크롤 없이 한 화면에 들어오는지 (전체 창 기준)
- [ ] 차량 연결 상태: 모의 주행 뒤 "받은 신호"가 늘지 않고 "시연·시험으로 만든 신호"로 따로 세어지는지
- [ ] 시연 기록 지우기 후 홈이 깨끗한지
