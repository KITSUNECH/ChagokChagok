# 차곡車곡

**차로 쓰는 성장일기.** 가족이 다니던 길을 운전석에서 따라 달리고, 차가 오늘의 운전을 일기로 남겨 주는 Pleos Connect 앱입니다.

- 아빠·엄마·친구가 평소 달린 길에 한마디를 얹어 **건네주면**, 받은 사람이 그 길을 달릴 때 **한마디를 남긴 자리에서** 들려줍니다.
- 주차하면 차량 신호(깜빡이, 브레이크, 와이퍼, 전조등, 기어, 좌석)로 **그림일기**를 씁니다. 두 사람의 주행이 한 장에 나란히 놓입니다: *같은 길, 다른 자리.*
- 익숙해진 길은 다시 다음 사람에게 건넵니다.

> 알파 0.1 · 기록은 이 차 안에만 저장됩니다.

## 실행 방법

1. Android Studio에서 Pleos Connect Emulator(2.1.0, API 34)를 실행합니다. AVD는 Cold boot로 설정합니다.
2. 이 프로젝트를 열고 ▶로 실행합니다. (제출용 APK는 `apk/` 폴더에 둡니다.)
3. Virtual Console을 엽니다.
   ```bash
   adb forward tcp:8088 tcp:8088
   ```
   브라우저에서 `http://127.0.0.1:8088/` 을 엽니다.
4. 처음 실행하면 시작 안내가 나옵니다. 운전자 이름, 운전 경험, 함께 쓰는 사람, 위치·날씨·음성 사용 여부를 고릅니다. 위치 권한 요청이 뜨면 허용합니다.

## 시연 순서 (같은 길, 다른 자리)

1. **설정 › 예시 길과 친구 넣기**를 누릅니다. 아빠가 건넨 "할머니 댁 가는 길"(한마디 2개, 각 한마디에 자리 좌표)과 친구 민수의 연습·추천 장소가 들어옵니다.
   직접 만들려면: 운전석을 **아빠**로 바꾸고 Virtual Console에서 기어 D → 깜빡이·브레이크 → P로 일기를 쓴 뒤, 일기에서 **이 길 건네주기**를 누릅니다.
2. 운전석을 **나**로 바꿉니다. **오늘**에 아빠가 건넨 길이 나타납니다.
3. **출발 준비**에서 깜빡이(양쪽), 와이퍼, 전조등, 기어(R→P)를 Virtual Console로 조작하면 하나씩 불이 들어오고 효과음이 납니다.
4. **이 길로 출발** → 출발 전 확인(내비 목적지, 연료, 워셔액, 안전벨트, 타이어, 의자, 도착지 날씨, 한마디 목록)을 봅니다.
5. Virtual Console에서 기어를 D에 놓으면 기록이 시작되고 주행 화면만 남습니다.
   - **한마디를 그 자리에서 듣기**: 에뮬레이터의 ⋯ › Location › Routes에서 **Import GPX/KML**로 `tools/예시길.gpx`를 불러와 재생하면, 차가 예시 길을 따라 움직이고 한마디를 남긴 자리 150m 안에서 한마디가 나옵니다. (예시 길의 좌표는 이 GPX와 같습니다.)
   - 위치가 움직이지 않는 환경이면 출발 전 화면의 **모의 주행 (시연용)** 을 씁니다. 화면에 "모의 주행 · 시연용"이 표시되고, 이 기록은 졸업·분석에서 빠집니다.
6. 깜빡이와 브레이크를 몇 번 조작하고 기어를 P에 놓으면 **일기**가 나옵니다. 두 사람의 주행 그림, 원고지(또는 줄글), 도장, **이 기록의 근거**, **주행 타임라인**을 봅니다.
7. 일기에서 **아빠에게 다녀왔다고 알리기**, **함께 차곡에 올리기**, **이 길 건네주기**를 눌러 봅니다.
8. **일기장 › 기록 분석**에서 주행마다 거리, 돌기 전 깜빡이 비율, 1km당 브레이크, 후진 뒤 기어 전환 추세를 봅니다.

**설정 › 시험용 신호**는 가상 콘솔에 없는 조작(내비 회전 안내, 표시등 등)을 시험하는 도구입니다. 실제 차량 신호가 아니므로 시연 영상에는 Virtual Console의 실제 신호를 씁니다.

## 구조

| 파일 | 하는 일 |
|---|---|
| `MainActivity.kt` | 화면 이동, 사이드바·탭, 주행 모드 전환, 차 신호 연결 |
| `Trip.kt` | 주행 한 번: 시작·종료, 위치로 한마디 재생, 회전 전 깜빡이, 모의 주행, 일기 만들기 |
| `Car.kt` | Vehicle SDK·NaviHelper SDK 신호를 모은다 |
| `Voice.kt` · `Places.kt` · `Restrictions.kt` | TextToSpeech SDK, FusedLocation SDK, CarUxRestrictions |
| `Writer.kt` | 기록을 사실만으로 된 일기 문장으로 (점수 없음) |
| `Model.kt` | 주행, 건네준 길, 일기, 설정의 저장 |
| `*Screen.kt` | 오늘, 출발 준비, 출발 전, 주행, 일기, 건네주기, 일기장·분석, 함께 차곡, 내 길, 설정, 시작 안내 |
| `Design.kt` · `Kit.kt` · `Icons.kt` · `Overlay.kt` | 색(낮/밤), 글꼴, 부품, 아이콘, 시트 |
| `Charts.kt` · `Views.kt` | 추세선·막대·타임라인 차트, 주행 그림, 원고지, 표시등 |

화면 확인: `./gradlew testDebugUnitTest --tests '*ScreenshotTest*'` 를 실행하면 넓은 창·밤·좁은 창의 모든 화면이 `build/shots/` 에 PNG로 저장됩니다.

## 데이터와 외부 전송

- 일기, 주행 경로, 건넨 길은 이 차(앱) 안에만 저장됩니다.
- 길을 건넬 때는 출발한 곳 근처 500m를 빼고, 목적지와 한마디를 남긴 자리만 함께 갑니다.
- **날씨**(켜 둔 경우): 목적지 또는 도착한 곳의 좌표만 Open-Meteo 공개 예보로 보냅니다.
- **일기 문장 다듬기**(선택): `local.properties`에 `anthropic.api.key`를 넣어 빌드한 경우에만, 일기 초안·운전자 이름·장소 이름·최근 일기의 핵심 문장이 Anthropic API로 갑니다. 키는 APK 안에 들어가므로 제출용 빌드에는 넣지 않습니다. 키가 없으면 차량 기록으로 규칙에 따라 씁니다.

## 한계

- 다른 차를 쓰는 가족·친구와의 연결은 계정과 서버가 필요해 구현하지 않았습니다. 지금은 한 차 안에서 운전석(프로필)을 바꿔 가며 씁니다.
- 글레오 호출(`assets/schema.json`, `GleoReceiver`)은 구현해 두었지만, 공모전 참가팀은 Gleo Interface 검토·승인을 신청할 수 없어 꺼 두었습니다.
- 안전벨트 체결 상태는 에뮬레이터에서 바꿀 수 없을 수 있어 출발 준비의 필수 항목에서 뺐습니다.
- 법규 문구는 출처와 시행일을 함께 적었습니다. 최신 법령은 국가법령정보센터에서 확인하세요.
