# 차곡차곡 (ChagokChagok)

> **차가 내 운전을 기억했다가, 같은 길을 다시 달릴 때 내가 늘었다는 걸 보여 준다.**

자주 가야 하는 길(출퇴근·병원·마트)을 익히는 운전자를 위한 Pleos Connect 앱입니다. 장롱면허·초보뿐 아니라, 20~30년 무사고 운전자도 "비 오는 밤의 차선 변경은 여전히 어렵다"고 말합니다([사용자 인터뷰](docs/참고자료_사용자인터뷰_요약.pdf)).

![앱 화면 흐름](docs/media/flow.gif)

## 이 앱이 하는 일: 네 단계

| 단계 | 하는 일 | 쓰는 Pleos SDK·API |
|---|---|---|
| **① D · 차가 기억해요** | 기어를 D에 놓으면 기록을 시작합니다. 깜빡이·브레이크·**차선 변경**(깜빡이 + 조향각, 깜빡이를 켜고 기다린 시간)·내비 재탐색·"천천히"를 청한 곳을 그 순간의 위치와 함께 남깁니다. 누를 것은 없습니다. | Vehicle SDK, AAOS `GEAR_SELECTION`, NaviHelper SDK, FusedLocation SDK |
| **② P · 돌아봐요** | 주차하면 "이 길을 돌아봐요"에 차가 본 사실만 보여 줍니다(예: "깜빡이를 켜고 12초 기다린 뒤 차선을 바꿨어요"). 기억해 둘 말은 운전자가 고르거나 고쳐 씁니다. 바쁘면 나중에, 홈의 "돌아볼 길"에 남습니다. | 앱 안 기록 |
| **③ 다시 갈 때 · 그 근처에서** | 같은 곳에 다시 가면 출발 전에 지난번 한마디를 보여 주고, 남긴 곳 근처(합류 구간은 400m 앞)에서 소리로 들려줍니다. 끼어드는 순간에는 말하지 않습니다. | FusedLocation `addProximityAlert`, TextToSpeech SDK, 오디오 포커스 |
| **④ 늘었는지 · 차와 내가 함께** | 같은 길을 끝까지 다녀온 기록끼리 **앱이 먼저 판단**하고(늘었어요/비슷해요/쉽지 않았어요), 운전자의 느낌과 합쳐 최종 평가를 냅니다. "이 길의 나"에서 지표별 그래프로 봅니다. | Vehicle SDK(연비·브레이크), 앱 안 분석 |

**앱의 판단 규칙 (공개)**: 처음 세 번의 평균과 비교 · 습관 지표(돌기 전 깜빡이, 차선 변경 전 기다림, 재탐색, 주차)는 무겁게, 길 상황에 흔들리는 지표(브레이크, 연비)는 가볍게, 걸린 시간은 참고만 · 시간대·비·밤이 다르면 절반만 반영 · 합쳐서 ±10%로 판단 · 지난 기록 수로 확신도 표시. 구현은 `Growth.kt`, 테스트는 `GrowthTest.kt`.

## 실행 방법

1. Android Studio에서 **Pleos Connect Emulator 2.1.0**(Android API 34)을 실행합니다. AVD는 Cold boot를 권장합니다.
2. 이 저장소를 열고 ▶로 실행하거나, `apk/`의 APK를 설치합니다.
   ```bash
   adb install -r apk/<APK 파일 이름>
   ```
3. 차량 신호는 **Virtual Console**로 바꿉니다.
   ```bash
   adb forward tcp:8088 tcp:8088
   ```
   브라우저에서 `http://127.0.0.1:8088/` 을 엽니다.
4. 처음 실행하면 시작 모션과 시작 안내(7단계)가 나옵니다. 위치 권한과 위치 사용 동의를 물으면 허용합니다.
5. **2분 시연**: 설정 › 연결 › 차량 연결 상태 › 시연 도구 › **시연: 회사 가는 길, 네 번째 출근** → 모의 주행 (시연용) → 도착하면 기어 P. 자세한 순서는 [시연 가이드](docs/시연가이드.md).

### 필요한 설정

- **위치 권한**(`pleos.car.permission.FUSED_LOCATION`, 실행 중 허락): 한마디를 남긴 곳 근처에서 들려주고, 그 순간의 위치를 남기는 데 씁니다. 운전자마다 따로 동의를 받습니다.
- **기록 중 알림**: 기록 중에는 앞쪽 서비스(알림 "차곡차곡 기록 중")로 내비 전체 화면·앱 전환에도 기록이 유지됩니다.
- **선택: 일기 문장 다듬기(생성형 AI)** — 설정 › 위치와 개인정보 › 일기 문장 다듬기에서 Anthropic API 키를 넣으면 켜집니다. 키는 저장소와 APK에 들어 있지 않고, 넣으면 기기 안 암호화 저장소에만 둡니다.
- **선택: 시연 도구** — 설정 › 연결 › 차량 연결 상태 › 시연 도구(공모전판에만 있음). 화면에 모두 "시연용"·"예시"로 표시됩니다.

## 무엇이 실제이고 무엇이 시연용인가

공개된 Pleos Playground 개발 문서의 SDK·API로 구현했고, 문서에 없는 기능만 시연용으로 표시했습니다.

| 기능 | 구분 | 쓰는 SDK·API |
|---|---|---|
| 주행 기록 (깜빡이·브레이크·와이퍼·전조등·안전띠·좌석·크루즈·주행거리) | 실제 | Vehicle SDK (신호마다 `check…Capabilities` 후 등록) |
| 기어 D에서 기록 시작, P에서 마침 | 실제 | AAOS `CarPropertyManager` `GEAR_SELECTION` |
| 차선 변경 기록 (깜빡이를 켜고 기다린 시간, 비·밤) | 실제 (추정) | Vehicle SDK 깜빡이 + `SteeringWheelAngle`. 회전(내비 300m 안 안내, 조향 30° 초과)은 뺌 |
| 이번 주행 연비 (전기차는 전비) | 실제 | Vehicle SDK Fuel `CurrentFuelEconomy` / EvBattery `CurrentEvEfficiency` |
| 주차 후 돌아보기 (재탐색·브레이크·차선 변경·천천히, 그 순간의 위치) | 실제 | NaviHelper `onReRouteEnded`(앱이 요청한 재탐색은 제외), FusedLocation |
| 같은 곳 알아보기 (내비 목적지, 또는 주차 위치 250m 안) | 실제 | FusedLocation, 앱 안 기록 |
| 남긴 곳 근처에서 한마디 (반경 150m + 진행 방향 100° 안) | 실제 | FusedLocation `addProximityAlert` + 위치 거리 확인 |
| 앱의 판단 + 내 느낌, "이 길의 나" 그래프 | 실제 | 앱 안 분석 (`Growth.kt`) |
| 소리로 알려 주기 (우선순위·중복 제거·때 지난 말 버리기, 끊긴 한마디는 다시) | 실제 | TextToSpeech SDK (ON_DEVICE), 오디오 포커스 |
| 달리는 동안 말로: 천천히·여기 한마디 남기기·최근 일기 읽기 | 실제 | Gleo AI App Integration |
| 주행 중 화면 제한·입력 막기 (신호를 못 받으면 기어로, 기어도 모르면 주행 중으로) | 실제 | CarUxRestrictions (`activeRestrictions`) |
| 기록 중 알림 | 실제 | Android 앞쪽 서비스 (specialUse) |
| 엔진오일·브레이크액·워셔액 부족 알림 | 실제 | Vehicle SDK Safety |
| 이 차의 기어 (제조사 확인) | 실제 | Vehicle SDK CarInfo `getVINInfo` (차종은 운전자가 고름) |
| 같은 차를 함께 쓰는 사람 (운전석 바꾸기, 길 건네기) | 실제 | 앱 안 프로필 |
| 시연: 회사 가는 길, 네 번째 출근 (예시 기록 3개 + 모의 주행) | **시연용** | 예시 기록은 "예시", 모의 주행은 "시연용"으로 표시. 실제 기록·성장 지표와 섞이지 않음 |
| 다른 차의 가족·친구와 잇기 (Pleos 계정 연동, 같이 가기) | **시연용** | 공개 API 없음 → [향후 계획](docs/향후계획.md) |
| 표시등(경고등) 화면 확인 | **시험용 신호** | 표시등 API는 비공개 권한이라 쓰지 않음 |

### 인터뷰에서 나왔지만 앱에서 하지 않는 것

- **차선 변경 순간에 옆 차의 속도·거리로 "지금 들어가세요"를 알려 주기**: 공개 SDK에 주변 차량 데이터가 없고, 실시간 판단은 제조사가 검증하는 안전 기능입니다. 앱은 지난 기록으로 그 구간 **전에** 미리 준비시키고, 드라이빙 뷰에 후측방 센서 정보를 "여유/주의"로 보여 주는 것은 플랫폼 제안으로 정리했습니다.
- **실시간 우회 경로·일반 교통량 통계**: 내비의 기능이고 공개 API가 없습니다. 앱은 내 기록과 같은 차 가족의 기록으로 비교합니다.

## 데이터와 외부 전송

- 일기, 주행 경로, 건넨 길은 이 차(앱) 안에만, 안드로이드 키스토어 키로 암호화해 저장합니다. 앱 서버는 없습니다.
- 위치는 운전자마다 동의를 받고, 동의하지 않은 운전자의 위치는 쓰지도 남기지도 않습니다.
- 길을 건넬 때는 출발한 곳 근처 500m를 빼고, 목적지와 한마디를 남긴 자리만 함께 갑니다.
- **날씨**(켜 둔 경우): 목적지 좌표를 소수 둘째 자리로 줄여 Open-Meteo 공개 예보로 보냅니다.
- **일기 문장 다듬기**(키를 넣은 경우): 일기 초안만 Anthropic API로 갑니다. 초안에 없는 숫자가 들어간 문장은 쓰지 않고, 원래 문장으로 되돌리거나 신고할 수 있습니다.
- 차량 마이크 음성은 외부로 보내지 않습니다.

## 한계

- 앱의 판단 규칙(무게, ±10%)은 직접 정한 규칙입니다. 사용성 관찰로 조정할 계획입니다.
- 차선 변경은 깜빡이와 조향각으로 추정합니다. 조향각을 못 받으면 내비 경로 안내 중일 때만 깜빡이를 켠 시간으로 추정하고 "추정"이라고 표시합니다.
- "같은 길"은 두 경로가 70% 넘게(120m 안) 겹칠 때만 씁니다. 그렇지 않으면 "같은 곳"으로 부릅니다.
- 내비 재탐색은 길을 놓쳤다는 뜻이 아닐 수 있어 단정하지 않고 운전자가 확인하게 합니다.
- 기록 중 알림으로 앱이 정리되지 않게 하지만, 앱을 한 번도 켜지 않은 상태에서는 기록이 시작되지 않습니다.
- Pleos 계정 정보와 차종·트림을 읽는 공개 API가 없어, 이름과 차종은 운전자가 고릅니다. 운전석 바꾸기에는 잠금이 없습니다(다음 단계).
- 법규·안전 조작 문구는 법제처 생활법령정보, 정책브리핑, 현대자동차 사용설명서, 한국교통안전공단 자료로 확인했고 화면에 근거를 함께 적었습니다.
