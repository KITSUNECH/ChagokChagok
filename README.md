# 차곡차곡 (ChagokChagok)

> **차로 쓰는 성장일기.** 내 운전을 아는 차가 달리는 동안 말을 걸어 주고, 같은 길에서 내가 늘었는지 보여 준다.

면허를 딴 지 얼마 안 된 운전자를 위한 Pleos Connect 앱입니다. 차는 내 운전을 다 보고 있지만 경고음만 낼 뿐 말해 주지 않고, 운전이 늘고 있는지 확인할 방법도 없습니다. 20~30년 무사고 운전자도 "비 오는 밤의 차선 변경은 여전히 어렵다"고 말합니다([사용자 인터뷰](docs/참고자료_사용자인터뷰_요약.pdf)).

![앱 화면 흐름](docs/media/flow.gif)

## 일기 한 장 = 나 + 차량 데이터

| 언제 | 누가 | 하는 일 | 쓰는 Pleos SDK·API |
|---|---|---|---|
| **달리는 동안** | 차 | 기어를 D에 놓으면 기록을 시작합니다. 돌기 전에 깜빡이를 알려 주고, 차선 변경을 마치면 잘한 것만 한마디 합니다. 누를 것은 없습니다. | Vehicle SDK, AAOS `GEAR_SELECTION`, NaviHelper SDK, TextToSpeech SDK |
| **주차하면** | 차 + 나 | 일기 한 장이 생깁니다. 왼쪽은 차가 본 것(깜빡이, 차선 변경 전 기다림, 브레이크, 주차), 오른쪽은 나(오늘 한 줄, 다음의 나에게 한마디). 스크롤 없이 한 화면입니다. | Vehicle SDK, 앱 안 분석 |
| **다시 갈 때** | 차 | 남겨 둔 한마디를 그 자리 근처에서 소리로 들려줍니다. 끼어드는 순간에는 말하지 않습니다. | FusedLocation `addProximityAlert`, TextToSpeech SDK, 오디오 포커스 |
| **쌓이면** | 차 | 같은 길의 일기끼리 견줘 "늘었어요 / 비슷해요 / 쉽지 않았어요"를 말하고, 그래프로 보여 줍니다. | 앱 안 분석 (`Growth.kt`) |
| **물어보면** | 차 | "차곡차곡, 오늘 차선 변경 어땠어?"라고 묻거나 화면의 **차에게 물어보기**를 누르면 기록한 차량 신호로 답합니다. | Gleo AI App Integration, TextToSpeech SDK |

### 처음부터 끝까지: 운전의 흐름

| 시기 | 앱이 가진 것 | 앱이 하는 일 |
|---|---|---|
| 첫 주행 | 내가 고른 "요즘 신경 쓰이는 것", 내비가 아는 길 | 말을 걸고, 오늘 본 사실을 적습니다("5번 돌았고 그중 4번은 돌기 전에 깜빡이를 켰어요"). 오늘이 기준이 됩니다. |
| 처음 가는 길 | 평소의 나 (최근 주행의 습관) | 길은 처음이어도 습관은 따라다닙니다. 깜빡이와 차선 변경 전 기다림을 평소의 나와 견줍니다. |
| 같은 길 두 번째 | 그 길의 지난 일기 | 지난번과 달라진 값을 보여 줍니다. 한 번의 차이로는 늘었다고 말하지 않습니다. |
| 같은 길 서너 번째부터 | 흐름 | "늘었어요"를 판단하고 그래프로 보여 줍니다. |
| 익숙해진 뒤 | 쌓인 일기 | 같은 차를 쓰는 가족에게 길과 한마디를 건넬 수 있습니다. |

### 지키는 원칙

1. **진실된 차량 데이터.** 화면의 숫자와 차가 하는 말은 이 앱이 실제로 받은 차량 신호에서만 나옵니다. 시연·시험으로 만든 신호는 따로 세고 화면에 밝힙니다. 못 본 것은 못 봤다고 말합니다.
2. **공개된 Pleos 개발 문서만.** 문서에 없는 기능은 만들지 않고 향후 계획에 적습니다. 차는 옆 차를 볼 수 있지만 그 정보는 앱에 열려 있지 않으므로, 앱은 "지금 끼어드세요"라고 말하지 않습니다.
3. **한 화면에 한눈에.** 차 안에서 쓰는 화면이라 쓸어내리거나 여러 번 누르지 않게 했습니다. 달리는 동안은 말로, 질문은 한 번에 하나만.
4. **순간에는 칭찬만, 돌아보는 건 멈췄을 때.** 차선 변경을 마친 뒤 잘한 것만 말하고, 나머지는 주차 후 일기에 적습니다.
5. **같은 것끼리만 견준다.** 습관은 평소의 나와, 길 상황에 흔들리는 값은 같은 길의 지난번과, 주차는 같은 자리의 지난번과.
6. **다른 차와 잇는 기능은 아이디어 시연일 뿐.** 지금 Pleos에는 차와 차를 잇는 기능이 없습니다. "그 기능이 열린다면"이라는 전제로 가상의 친구를 보여 주는 화면이 공모전판에 있고, 모두 시연용이라고 표시합니다.

**앱의 판단 규칙 (공개)**: 같은 길의 지난 기록이 두 번 이상일 때만 판단(한 번뿐이면 달라진 값만 보여 줌) · 처음 세 번의 평균과 비교 · 습관 지표(돌기 전 깜빡이, 차선 변경 전 기다림, 재탐색, 주차)는 무겁게, 길 상황에 흔들리는 지표(브레이크, 연비)는 가볍게, 걸린 시간은 참고만 · 차선 변경 전 기다림은 3초 아래로 줄어든 만큼은 나아진 것으로 치지 않음(서두르기를 칭찬하지 않게) · 시간대·비·밤이 다르면 절반만 반영 · 합쳐서 ±10%로 판단 · 괄호 안 변화량은 화면에 보이는 값으로 계산. 구현은 `Growth.kt` · `Coach.kt`, 테스트는 `GrowthTest.kt`.

## 실행 방법

1. Android Studio에서 **Pleos Connect Emulator 2.1.0**(Android API 34)을 실행합니다. AVD는 Cold boot를 권장합니다.
2. 이 저장소를 열고 ▶로 실행하거나, `apk/`의 APK를 설치합니다.
   ```bash
   adb install -r apk/<APK 파일 이름>
   ```
3. 차량 신호는 **Virtual Console**로 바꿉니다.
   ```bash
   adb forward tcp:8088 tcp:8088
   ```
   브라우저에서 `http://127.0.0.1:8088/` 을 엽니다.
4. 처음 실행하면 시작 모션과 첫 설정(4단계: 소개 · 이름 · 어떤 운전자인지 · 위치와 소리)이 나옵니다. 위치·속도·알림 권한과 위치 사용 동의를 물으면 허용합니다.
5. **2분 시연**: 설정 › 시연 › **네 번째 출근 보기** → 모의 주행 (시연용) → 도착하면 기어 P. 자세한 순서는 [시연 가이드](docs/시연가이드.md).

### 필요한 설정

- **알림 권한**: 기록 중 알림을 보여 주려고 위치 권한과 함께 주차 중에 한 번 묻습니다.
- **속도 권한**(`android.car.permission.CAR_SPEED`, 실행 중 허락): 급하게 선 순간을 알아보는 데만 씁니다. 허락하지 않으면 급정거 없이 기록합니다.
- **위치 권한**(`pleos.car.permission.FUSED_LOCATION`, 실행 중 허락): 한마디를 남긴 곳 근처에서 들려주고, 그 순간의 위치를 남기는 데 씁니다. 운전자마다 따로 동의를 받습니다.
- **기록 중 알림**: 기록 중에는 앞쪽 서비스(알림 "차곡차곡 기록 중")로 내비 전체 화면·앱 전환에도 기록이 유지됩니다.
- **선택: 시연 도구** — 설정 › 시연 › 시연 도구(공모전판에만 있음). 화면에 모두 "시연용"·"예시"로 표시됩니다.

## 무엇이 실제이고 무엇이 시연용인가

공개된 Pleos Playground 개발 문서의 SDK·API로 구현했고, 문서에 없는 기능만 시연용으로 표시했습니다.

| 기능 | 구분 | 쓰는 SDK·API |
|---|---|---|
| 주행 기록 (깜빡이·브레이크·와이퍼·전조등·안전띠·좌석·크루즈·주행거리) | 실제 | Vehicle SDK (신호마다 `check…Capabilities` 후 등록) |
| 기어 D에서 기록 시작, P에서 마침 | 실제 | AAOS `CarPropertyManager` `GEAR_SELECTION` |
| 차선 변경 기록 (깜빡이를 켜고 기다린 시간, 비·밤) | 실제 (추정) | Vehicle SDK 깜빡이 + `SteeringWheelAngle`. 회전(내비 300m 안 안내, 조향 30° 초과)은 뺌 |
| 이번 주행 연비 (전기차는 전비) | 실제 | Vehicle SDK Fuel `CurrentFuelEconomy` / EvBattery `CurrentEvEfficiency` |
| 주차 후 돌아보기 (재탐색·브레이크·차선 변경·"여기 어려웠어요", 그 순간의 위치) | 실제 | NaviHelper `onReRouteEnded`(앱이 요청한 재탐색은 제외), FusedLocation |
| 같은 곳 알아보기 (내비 목적지, 또는 주차 위치 250m 안) | 실제 | FusedLocation, 앱 안 기록 |
| 남긴 곳 근처에서 한마디 (반경 150m + 진행 방향 100° 안) | 실제 | FusedLocation `addProximityAlert` + 위치 거리 확인 |
| 앱의 판단 + 내 느낌, "이 길의 나" 그래프 | 실제 | 앱 안 분석 (`Growth.kt`) |
| 소리로 알려 주기 (우선순위·중복 제거·때 지난 말 버리기, 끊긴 한마디는 다시) | 실제 | TextToSpeech SDK (ON_DEVICE), 오디오 포커스 |
| 달리는 동안 말로: 내 운전 물어보기·여기 어려웠어·여기 한마디 남기기 | 실제 (에뮬레이터에서 글레오 호출은 확인 필요) | Gleo AI App Integration (`ASK_MY_DRIVING` · `TAKE_IT_SLOW` · `SAVE_NOTE_HERE`) |
| 급하게 선 순간 (속도가 짧은 시간에 크게 줄어든 때) | 실제 (0.3.1에서 추가, 에뮬레이터 확인 필요) | AAOS `CarPropertyManager` `PERF_VEHICLE_SPEED` |
| 출발할 때 안전벨트 확인 (안 맸으면 화면과 말로) | 실제 | Vehicle SDK Seat `SeatBeltBuckledState` |
| 차에게 물어보기 (버튼, 글레오와 같은 답) · 요즘 신경 쓰이는 것부터 말하기 · 차선 변경 뒤 한마디 | 실제 | Vehicle SDK 기록 + 앱 안 분석(`Coach.kt`), TextToSpeech SDK |
| 첫 주행·처음 가는 길의 "오늘 차가 본 것" (기준에 비춘 사실, 평소의 나) | 실제 | Vehicle SDK 기록 + 앱 안 분석 |
| 주행 중 화면 제한·입력 막기 (신호를 못 받으면 기어로, 기어도 모르면 주행 중으로) | 실제 | CarUxRestrictions (`activeRestrictions`) |
| 기록 중 알림 | 실제 | Android 앞쪽 서비스 (specialUse) |
| 엔진오일·브레이크액·워셔액 부족 알림 | 실제 | Vehicle SDK Safety |
| 같은 차를 함께 쓰는 사람 (운전석 바꾸기, 길 건네기) | 실제 | 앱 안 프로필 |
| 시연: 회사 가는 길, 네 번째 출근 (예시 기록 3개 + 모의 주행) | **시연용** | 예시 기록은 "예시", 모의 주행은 "시연용"으로 표시. 실제 기록·성장 지표와 섞이지 않음 |
| 다른 차의 가족·친구와 잇기 (Pleos 계정 연동, 같이 가기) | **시연용** | 공개 API 없음 → [향후 계획](docs/향후계획.md) |
| 표시등(경고등) 화면 확인 | **시험용 신호** | 표시등 API는 비공개 권한이라 쓰지 않음 |

### 인터뷰에서 나왔지만 앱에서 하지 않는 것

- **차선 변경 순간에 옆 차의 속도·거리로 "지금 들어가세요"를 알려 주기**: 공개 SDK에 주변 차량 데이터가 없고, 실시간 판단은 제조사가 검증하는 안전 기능입니다. 앱은 지난 기록으로 그 구간 **전에** 미리 준비시키고, 드라이빙 뷰에 후측방 센서 정보를 "여유/주의"로 보여 주는 것은 플랫폼 제안으로 정리했습니다.
- **실시간 우회 경로·일반 교통량 통계**: 내비의 기능이고 공개 API가 없습니다. 앱은 내 기록과 같은 차 가족의 기록으로 비교합니다.

## 데이터와 외부 전송

- 일기, 주행 경로, 건넨 길은 이 차(앱) 안에만, 안드로이드 키스토어 키로 암호화해 저장합니다. 앱 서버는 없습니다.
- 위치는 운전자마다 동의를 받고, 동의하지 않은 운전자의 위치는 쓰지도 남기지도 않습니다.
- 길을 건넬 때는 출발한 곳 근처 500m를 빼고, 목적지와 한마디를 남긴 자리만 함께 갑니다.
- **날씨**(켜 둔 경우): 목적지 좌표를 소수 둘째 자리로 줄여 Open-Meteo 공개 예보로 보냅니다.
- 일기 문장을 생성형 AI로 다듬는 기능은 화면에서 뺐습니다. 키를 넣는 길이 없어 외부로 일기가 나가지 않습니다(코드 `AiDiary.kt`는 남아 있습니다).
- 차량 마이크 음성은 외부로 보내지 않습니다.

## 한계

- 앱의 판단 규칙(무게, ±10%)은 직접 정한 규칙입니다. 사용성 관찰로 조정할 계획입니다.
- 차선 변경은 깜빡이와 조향각으로 추정합니다. 조향각을 못 받으면 내비 경로 안내 중일 때만 깜빡이를 켠 시간으로 추정하고 "추정"이라고 표시합니다.
- "같은 길"은 두 경로가 70% 넘게(120m 안) 겹칠 때만 씁니다. 그렇지 않으면 "같은 곳"으로 부릅니다.
- 내비 재탐색은 길을 놓쳤다는 뜻이 아닐 수 있어 단정하지 않고 운전자가 확인하게 합니다.
- 기록 중 알림으로 앱이 정리되지 않게 하지만, 앱을 한 번도 켜지 않은 상태에서는 기록이 시작되지 않습니다.
- Pleos 계정 정보와 차종·트림을 읽는 공개 API가 없어, 이름과 차종은 운전자가 고릅니다. 운전석 바꾸기에는 잠금이 없습니다(다음 단계).
- 급정거는 속도 신호(AAOS `PERF_VEHICLE_SPEED`)로 알아봅니다: 시속 20km 넘게 달리다 1초에 약 시속 11km(3m/s²) 넘게 줄었을 때. 직접 정한 기준이고, 속도 신호를 받지 못한 주행에서는 급정거를 말하지 않습니다. 급조향과 가속은 아직 재지 않습니다.
- 달리는 동안의 말은 기록된 내 조작에 대한 것뿐입니다. 주변 차의 위치·속도는 앱에 열려 있지 않습니다.
- 이 판(0.3.2)의 구조 개편은 단위·화면 테스트로 확인했고, Pleos Connect 에뮬레이터에서의 실기 확인은 제출자가 따로 해야 합니다.
