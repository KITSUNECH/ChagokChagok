# 차곡차곡 (ChagokChagok)

> **차가 내 운전을 기억했다가, 같은 길을 다시 달릴 때 내가 늘었다는 걸 보여 준다.**

자주 가야 하는 길(병원·직장·마트)을 혼자 익히려는 장롱면허·초보 운전자를 위한 Pleos Connect 앱입니다.

1. **차가 기록한다** — 기어를 D에 놓으면 기록을 시작합니다. 깜빡이·브레이크·내비 재탐색, 운전자가 "천천히"를 청한 곳을 그 순간의 위치와 함께 남깁니다.
2. **운전자가 의미를 정한다** — 주차하면 "오늘을 돌아봐요"에 차가 본 사실만 보여 줍니다(예: "이 근처에서 내비가 경로를 다시 찾았어요"). 기억해 둘 일이 있었는지는 운전자가 고르거나 고쳐 씁니다.
3. **다음 운전에 쓴다** — 같은 곳에 다시 가면 출발 전에 지난번 한마디를 보여 주고, 남긴 곳 근처에서 소리로 들려줍니다.
4. **늘었는지는 내가 답한다** — 주차 후 "한마디가 도움이 됐나요?", "지난번보다 어땠어요?"에 답합니다. 시간·브레이크 같은 숫자는 판정 없이 달라진 것만 보여 줍니다.

같은 차를 함께 쓰는 가족은 익숙해진 길에 한마디를 얹어 건넬 수 있습니다. 해낸 일은 오른쪽 **성장 바**에 쌓입니다: 익히기(차와 친해지기) → 넓히기(다닐 곳 늘리기) → 차곡차곡(같은 곳에 다시, 한마디가 도움, 더 편했어요, 익숙해진 길 건네기).

## 두 가지 판

| 판 | 쓰임 | 시연용 기능 |
|---|---|---|
| `contest` (기본) | 공모전 제출·시연 | 들어 있음. 기본은 꺼짐, 켜면 화면에 "시연용" 표시 |
| `market` | Pleos App Market 탑재 준비 | **없음** (가상 친구, 모의 주행, 예시 길, 시험용 신호를 빼고 빌드) |

Android Studio의 Build Variants에서 `contestDebug` / `marketDebug` 를 고르거나, `./gradlew assembleContestRelease` · `./gradlew assembleMarketRelease` 로 빌드합니다.

## 실행 방법

1. Android Studio에서 **Pleos Connect Emulator 2.1.0**(Android API 34)을 실행합니다. AVD는 Cold boot를 권장합니다.
2. 이 저장소를 열고 ▶로 실행하거나, `apk/`의 APK를 설치합니다.
   ```bash
   adb install -r apk/<APK 파일 이름>
   ```
3. 차량 신호는 **Virtual Console**로 바꿉니다.
   ```bash
   adb forward tcp:8088 tcp:8088
   ```
   브라우저에서 `http://127.0.0.1:8088/` 을 엽니다.
4. 처음 실행하면 시작 안내(7단계)가 나옵니다. 이름, 운전 경험, 면허 딴 해, 혼자/함께, 위치·음성·날씨 사용 여부를 고릅니다. 위치 권한을 물으면 허용합니다.

### 필요한 설정

- **위치 권한**(`pleos.car.permission.FUSED_LOCATION`, 실행 중 허락): 한마디를 남긴 자리에서 들려주는 데 씁니다. 운전자마다 따로 동의를 받습니다.
- **선택: 일기 문장 다듬기(생성형 AI)** — 설정 › 위치와 개인정보 › 일기 문장 다듬기에서 Anthropic API 키를 넣으면 켜집니다. 키는 저장소와 APK에 들어 있지 않고, 넣으면 기기 안 암호화 저장소에만 둡니다. 키가 없으면 차량 기록으로 규칙에 따라 씁니다.
- **선택: 시연용 기능** — 설정 › 연결 › 차량 연결 상태 › 시연 도구(공모전판에만 있음)에서 켭니다(기본은 꺼짐). 화면에 모두 "시연용"으로 표시됩니다.

## 무엇이 실제이고 무엇이 시연용인가

이번 공모전은 공개된 Pleos Playground 개발 문서의 SDK·API 범위에서 개발합니다. 문서에 있는 기능은 실제로 구현했고, 문서에 없는 기능만 시연용으로 표시했습니다.

| 기능 | 구분 | 쓰는 SDK·API |
|---|---|---|
| 주행 기록 (깜빡이·브레이크·와이퍼·전조등·안전띠·좌석·크루즈·주행거리) | 실제 | Vehicle SDK (신호마다 `check…Capabilities` 후 등록) |
| 기어 D에서 기록 시작, P에서 일기 | 실제 | AAOS `CarPropertyManager` `GEAR_SELECTION` |
| 엔진오일·브레이크액·워셔액 부족 알림 | 실제 | Vehicle SDK Safety |
| 이 차의 기어 (제조사 확인) | 실제 | Vehicle SDK CarInfo `getVINInfo` (차종은 운전자가 고름) |
| 회전 안내·목적지·도착·편안한 길·내비 화면 열기 | 실제 | NaviHelper SDK |
| 주차 후 돌아보기 (재탐색·브레이크·천천히 순간과 위치) | 실제 | NaviHelper `onReRouteEnded`(앱이 요청한 재탐색은 제외), Vehicle SDK 브레이크, FusedLocation 위치 |
| 남긴 곳 근처에서 한마디 (반경 150m + 진행 방향 100° 안) | 실제 | FusedLocation SDK `addProximityAlert` + 위치 거리 확인 |
| 같은 곳 다시 가기와 비교 (끝까지 다녀온 실제 주행끼리) | 실제 | 앱 안 기록. 경로가 70% 넘게 겹치면 "같은 길", 아니면 "같은 곳" |
| 소리로 알려 주기 (우선순위·중복 제거·때 지난 말 버리기) | 실제 | TextToSpeech SDK (ON_DEVICE), 오디오 포커스 |
| 달리는 동안 말로: 천천히·여기 한마디 남기기·최근 일기 읽기 | 실제 | Gleo AI App Integration |
| 주행 중 화면 잠금, 입력 막기, 긴 글 줄이기 (신호를 못 받으면 기어로, 기어도 모르면 주행 중으로 판단) | 실제 | CarUxRestrictions (`activeRestrictions`) |
| 같은 차를 함께 쓰는 사람 (운전석 바꾸기) | 실제 | 앱 안 프로필 |
| 다른 차의 가족·친구와 잇기 (Pleos 계정 연동, 같이 가기) | **시연용** | 공개 API 없음 → 향후 계획 (`docs/향후계획.md`) |
| 모의 주행 | **시연용** | 에뮬레이터에서 내비가 차를 움직이지 않아 경로를 흉내 냄 |
| 표시등(경고등) 화면 확인 | **시험용 신호** | 표시등 API는 비공개 권한이라 쓰지 않음 |

## 시연 순서

**대표 장면: 첫 방문 → 돌아보기 → 다시 가기 → 그 근처에서 한마디 → 지난번보다 어땠는지** (에뮬레이터 위치 재생 두 번)

1. **첫 방문**: 내비에 목적지를 넣고, 에뮬레이터 ⋯ › Location › Routes에서 `tools/예시길.gpx`를 재생합니다. Virtual Console에서 기어 D → 가는 길 중간에 브레이크를 3번 → 기어 P.
2. **오늘을 돌아봐요**: 주차하면 일기 위에 "브레이크를 3번 밟은 구간이에요"가 나옵니다. "돌아보기" → 추천 문장을 고르거나 직접 고쳐 써서 남깁니다.
3. **다시 가기**: 홈의 "다시 가 볼까요?"에서 그곳을 고르면 출발 전 화면에 "이번에 참고할 지난번 한마디"가 보입니다. 같은 경로를 다시 재생하고 D.
4. **그 근처에서**: 남긴 곳 근처에 오면 "내 한마디. …"를 소리로 들려줍니다. 달리는 동안 화면은 회전 전 깜빡이 카드와 한마디 카드만 보입니다.
5. **늘었는지는 내가**: P에 놓으면 "들은 한마디, 도움이 됐나요?", "지난번보다 어땠어요?"를 묻습니다. 답하면 성장 바의 차곡차곡 단계에 칸이 쌓이고, 일기에는 같은 길/같은 곳 비교가 나옵니다.

함께 보여 줄 것

- **가족이 건넨 길**: 설정 › 차량 연결 상태 › 시연 도구 › 예시 길과 친구 넣기 → 홈의 "아빠가 건네준 길" → 출발. 위치가 움직이지 않는 환경이면 출발 전 화면의 **모의 주행 (시연용)**을 씁니다(성장 바·비교에서 빠짐).
- **출발 준비**: 깜빡이(양쪽)·와이퍼·전조등을 Virtual Console로 켜면 하나씩 확인됩니다. 기어는 실제로 넣지 않고 "이 차의 기어" 그림으로 확인합니다. 차종을 고르면 안전 조작 10가지가 나옵니다.
- **달리는 동안 말로**: 글레오에게 "차곡차곡, 천천히 갈래"(이곳을 기억하고 편안한 경로 요청), "차곡차곡, 여기 한마디 남겨 줘"라고 말합니다.

## 데이터와 외부 전송

- 일기, 주행 경로, 건넨 길은 이 차(앱) 안에만, 안드로이드 키스토어 키로 암호화해 저장합니다. 앱 서버는 없습니다.
- 위치는 운전자마다 동의를 받고, 동의하지 않은 운전자의 위치는 쓰지도 남기지도 않습니다.
- 길을 건넬 때는 출발한 곳 근처 500m를 빼고, 목적지와 한마디를 남긴 자리만 함께 갑니다.
- **날씨**(켜 둔 경우): 목적지 좌표만 Open-Meteo 공개 예보로 보냅니다.
- **일기 문장 다듬기**(키를 넣은 경우): 일기 초안만 Anthropic API로 갑니다. 초안에 없는 숫자가 들어간 문장은 쓰지 않고, 일기에서 원래 문장으로 되돌리거나 신고할 수 있습니다.

## 한계

- Pleos 계정 정보(이름 등)를 읽는 공개 API가 없어, 첫 설정에서 이름을 직접 입력합니다.
- 차종·트림을 알려 주는 공개 API가 없어, 기어 안내는 운전자가 차종을 한 번 고릅니다.
- "같은 길"은 두 경로가 70% 넘게(120m 안) 겹칠 때만 씁니다. 위치 동의가 없으면 목적지 이름이 같은 "같은 곳"끼리 비교합니다.
- 내비 재탐색은 길을 놓쳤다는 뜻이 아닐 수 있어, "길을 놓쳤다"고 단정하지 않고 운전자가 확인하게 합니다. 위치가 없을 때 순간의 자리는 진행 정도로 추정합니다("위치는 대략" 표시).
- 기록은 앱 화면(Activity)에 붙어 있습니다. 끊기면 다시 열 때 이어 가지만, 프로세스가 정리된 동안의 신호는 남지 않습니다. 포그라운드 서비스로 옮기는 것은 다음 단계입니다.
- 같은 차의 운전석 바꾸기에는 잠금이 없습니다(다음 단계).
- 법규·안전 조작 문구는 법제처 생활법령정보, 정책브리핑, 현대자동차 사용설명서, 한국교통안전공단 자료로 확인했고 화면에 근거를 함께 적었습니다.
